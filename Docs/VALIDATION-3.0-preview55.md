# APEX Lab 3.0 Preview 55 验证记录

## 驾驶学院

用 240 Hz 车辆求解器执行固定模拟量指令和独立键盘按压序列。Porsche 911 Carrera 4S 的定点停车制动标记设在 276 米，停车框中心为 313 米。模拟量和键盘分别停在 310.98 米和 313.48 米，均得金牌。911 的松刹入弯分别得金牌和铜牌。Lamborghini Centenario 的湿地出弯用两种输入均得金牌。

逐步松刹要求转向负荷存在、踏板正在减小且制动液压同步下降。911 的连续试跑为 1.021 秒，重新踩下刹车后最长一段为 0.496 秒。短暂停在同一开度的试跑为 0.992 秒，键盘模拟踏板回程为 0.017 秒。直接松开、持续保持压力、固定开度附近的微小抖动和滑行均为零。奖牌门槛和课程成绩存档格式沿用。课程套件通过 62 项检查。

## 发布素材

两段试听由 Preview 55 的 Core Audio 内存渲染生成。依照同一套踏板工况依次渲染 [Porsche 911](Audio-3.0/Porsche911-audio.wav) 和 [Lamborghini Centenario](Audio-3.0/Centenario-audio.wav)，每段是 8 秒、44.1 kHz 双声道 16 位 PCM。包内图片取自 Preview 55 的选车界面、湿地驾驶位和展厅。素材署名与许可随包提供。

## 两车车库与旧存档

选车、驾驶学院、三个巡回赛和车辆展示使用 Porsche 911 Carrera 4S 与 Lamborghini Centenario。原生应用通过 79 项菜单检查。用临时旧存档验证了 9 项车型迁移场景，退役车型的驾驶选择回到 911，历史比赛和杯赛保留原车型编号，旧圈速、分析和车辆设置保留原键。两款现行车型继续使用编号 2 和 5。另有 6 项存档恢复检查通过。

## 车辆实测

两款车在六条赛道上均完成干湿地两圈四车赛。175 项场景检查覆盖两套原模型、活动面板、驾驶位、独立镜面和悬架动画。911 三档座高下左、右外镜的最低无遮挡采样分别为 17/18 和 16/18，中央镜为 18/18。Centenario 两侧外镜均为 23/24。Centenario 展厅驾驶位调整了原碳纤维和仪表台的反光，并在车内视角移除遮暗视线的夹层玻璃。车外继续绘制这层玻璃。

车身质量、轮胎与部分制动参数仍为模拟设定。911 与 Centenario 的中高转音层分别借用 GT3 RS 与 Aventador SVJ 的录音，精确音源见[第三方署名](../Assets/THIRD-PARTY-NOTICES.md)。原生验证使用静音测试应用和临时数据目录，音频测量在离线缓冲区进行。实体和虚拟手柄均未参与本轮验证。

完整非手柄套件通过 907 项检查。随后对展厅夹层玻璃的最终实现独立复跑 175 项场景检查。原生测试应用另通过 12 项驾驶学院检查和 14 项比赛周末检查。两段音频试听使用签入的双车参数与同一组驾驶输入离线生成。
