# APEX Lab 3.0 Preview 31 赛道坡形与路肩

各条赛道按正负曲率确定弯内路肩，持续弯道接近出口时加入外侧路肩。路肩宽度、高度和侧向位置来自同一份逐米采样数据，渲染法线与轮胎接地使用同一坡面定义。维修道汇入口在并线区域把路肩高度逐渐收平。

河谷环线的中心线相对起点从 +7.4 m 到 −5.1 m。三处横坡分别为 +3.7%、−5.3% 和 +4.5%。进出维修道、发车格与计时线保持水平。轮胎法向载荷、重力坡分量、降雨水膜以及AI引导速度共同使用这组坡形。

车阵测试覆盖六条赛道的干地和北环、河谷环线的湿地。俱乐部短环曾出现对手把超车意图带进连续弯并冲出赛道。现在临近弯道或持续超车六秒后考虑归线，归线位置旁仍有车时继续避让。
