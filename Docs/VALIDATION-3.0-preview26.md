# APEX Lab 3.0 Preview 26 车辆展示

在开始界面或选车页打开「车辆展示」。鼠标拖动可以环绕车辆，滚动可以缩放。车头、侧面、车尾与座舱都有固定入口。用「选用此车」把当前展示车型带回开始界面，直接退出会回到原来的选车状态。

| 车型 | 可动部件 |
| --- | --- |
| Concept GT | 左右车门、前倾式机盖。前灯随原模型的机盖移动。 |
| Ferrari 458 | 左右车门、前备厢盖。 |
| Porsche 911 Carrera 4S | 前备厢盖。两扇车门采用原模型的固定车身网格。 |
| BMW M3 E30 | 左右车门、前倾式机盖和行李厢盖。 |
| Mazda MX-5 | 左右车门、机盖。前灯打开时两只灯壳升起。 |
| Lamborghini Centenario | 左右剪刀门、前备厢盖和后机舱盖。 |
| Lotus Elise | 左右车门、前检修盖和后机舱盖。 |
| Honda e | 四扇车门独立开合，前舱盖可打开。 |

八辆车都能独立控制前灯、尾灯与座舱照明。部分车型提供双闪。展厅直接使用经许可的车身、内衬、玻璃、灯组和座舱几何。机舱、门框与盖板内侧的完整程度取决于各作者提供的模型。[车型原作者和适配说明](../Assets/Vehicles/README.md)

完整回归通过 867 项。展厅逐车校验了分组前后的原始三角形数量、铰链转动和复位、灯光独立状态、MX-5 翻灯的升降以及座舱旋转和缩放。另用原生游戏控制界面通过 9 项检查，覆盖八车的按钮布局、展厅独立状态、退出后恢复选车，以及选用车辆后进入练习。
