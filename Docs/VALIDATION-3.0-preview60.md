# APEX Lab 3.0 Preview 60 验证记录

## 湿地起步

附着力低时，起步离合器会根据曲轴和传动轴转速差限制正向扭矩。用大奖赛湿地实路、冷胎、全油门、TCS 关闭复测。以 720 Hz 记录起步阶段实际传到各轮的扭矩和平均轮速。911 在两轴明显转得比曲轴快时仍持续正驱的时间由 250 毫秒降为零。在测量窗口内，911 和 Centenario 的车轮端机械能超出曲轴供应的能量分别由 42.13 kJ 和 27.91 kJ 降为零。轮胎仍会滑。TCS 3 的同条件对照下，两款车到 30 km/h 的时间保持在原来的 1.458 秒和 1.440 秒。

## 松刹与补刹

在北环滚动入弯，管路稳定在 11% 后把目标压力提高或降低 1.2 个百分点。旧版两辆车的压力增量到达九成需要 75.0 毫秒，减量需要 29.2 毫秒。新版本增量和减量都约为 29.2 毫秒。两车在干、湿地的 100–0 km/h 紧急停车距离变化均在 3 厘米内。小幅补刹可以在练习的 F8 刹车图上查看。

## 轻点方向键与反打

把键盘按下和放开的时刻写入 240 Hz 车辆物理输入。即使按下和放开都落在同一个物理步，也会按那段时间累计输入。在 100 km/h、使用「细腻」曲线的两车上，模拟一次 50 毫秒轮询延迟，并在其中点按方向键 20 毫秒。新版 911 的实际前轮转角峰值为 0.0359°，Centenario 为 0.0365°，与无延迟对照相同。旧版相同延迟下为 0.1260° 和 0.1267°。

## 试玩验收

- **湿地起步** · 暂停后用 TCS 3 的 911 从低速逐步给油，确认轮胎开始滑时动力接续是否自然。也可试 Centenario 作对照。
- **松刹入弯** · 在北环半踩刹车准备转向、逐步松开，再补一点刹车。用 F8 比较踏板行程、管路压力和方向盘角度。 [F8 示例](Driving-3.0/preview57-porsche-braking.jpg)
- **高速微调** · 在直道上轻点方向键修正线路，再长按测试反打。当前个人存档保留选定的 120 FPS、两车的「细腻」转向以及各自的 TCS 设置。

## 本地回归

975 项非手柄回归通过。另通过 46 项原生练习和存档检查、12 项原生驾驶学院检查、34 项含排位、比赛和回放的原生检查。AppKit 键盘事件对照中，两辆车的短点、左右连续修正和满舵反打结果在正常轮询和一次 50 毫秒卡顿下相同。所有运行使用隔离存档及静音输出，录音验证在内存中完成。
