# 赛车模拟器方向与 iRacing 公开技术参考

查阅日期：2026-11-04。以下为公开资料研究，没有获取或反编译 iRacing 程序；本项目不包含 iRacing 的程序、模型、纹理或车辆参数。

## 公开资料能够确认的方向

1. iRacing 将轮胎力、气动力、悬架弹簧与阻尼、发动机和传动、制动等子系统共同纳入动力学计算；轮胎表现取决于速度、载荷、滑移和温度等状态。公开文章阐述了物理建模思路，但并未公开可直接复制的完整求解器与标定数据。[Dave Kaemmer：The Sticking Points in Modeling Tires](https://www.iracing.com/the-sticking-points-in-modeling-tires/)
2. 官方车辆技术页强调多体系统、直接力计算和专有轮胎模型。获得相似画面不等于获得相似驾驶行为。[Car Technology](https://www.iracing.com/car-technology/)
3. 官方赛道技术页强调扫描几何、路面起伏与横坡，以及动态路面和天气。当前项目的原创平面赛道不能被视为已复现这些系统。[Track Technology](https://www.iracing.com/track-technology/)
4. 2026 年 8 月开发更新讨论了物理多线程架构和基于物理的照明等工作。它说明这类系统需要持续开发，并不能据此推导其私有实现。[Development Update: August 2026](https://www.iracing.com/iracing-development-update-august-2026/)

## 本项目 0.2 的实际调整

| 方面 | 0.1 | 0.2 |
| --- | --- | --- |
| 接地模型 | 前后轴聚合轮胎 | 四个独立接地点，分别计算轮速、滑移与作用力 |
| 垂向状态 | 视觉摇摆 | 四角弹簧/阻尼和车身升沉、侧倾、俯仰状态 |
| 轮胎 | 聚合侧向饱和函数 | 联合滑移的简化接地力模型，载荷敏感性和单状态热模型 |
| 制动与牵引辅助 | 力预算裁剪 | 根据轮速滑移调节的简化 ABS/TCS |
| 美术 | 程序生成的低模车、树、纯色地面 | 授权精细模型、完整内饰、扫描材质、HDR 环境照明 |
| 相机 | 当前 up 方向可能累积倾斜 | 使用固定世界向上参考，加入连续旋转回归检查 |
| 模型导入 | 无外部模型 | GLB 顶点、法线、UV、材质、层级与完整数值变换 |

这些是本项目的设计选择，不是对 iRacing 实现的逆向结论。

## 仍然需要验证或开发的内容

- 当前车辆参数是实验配置，尚无实车试验或厂家轮胎曲线用于标定。
- 四角弹簧模型尚不包含完整悬架几何、非簧载质量与轮胎胎体多体系统。
- 热模型只使用每轮一个温度状态，没有胎面分区、内部胎体温度或胎压演化。
- 没有扫描赛道高程、横坡、动态橡胶、动态天气、碰撞损伤、联网或比赛裁判。
- 发动机声音仍为合成占位音效。
- 当前已进行键盘与画面验证；Xbox 实体手柄没有连接，扳机与触觉效果需实测。

只有在车辆动力学、输入延迟、视角、碰撞和性能经过数据与实机验证后，才能评价模拟真实性。当前版本是面向这个方向的原型，不宣称达到 iRacing 水平。
