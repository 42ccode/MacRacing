# APEX Lab 3.0 Preview 49 松刹与赛中计时

## ABS 收尾

在主缸压力低于原有调节阈值后，卡钳阀门按原速率平滑恢复。八辆车在 240、720 和 1,440 Hz 的 3,888 组制动对照包含干地、湿地、积水、左右不同抓地、路肩和单侧草地。逐步松开时，阈值处的卡钳压力连续过渡。

350 毫秒松刹加转向的名义制动力矩上跳由单轮最高 4.27 牛·米降到零。持续重刹的干湿地停车距离相同，松刹结束速度差不超过 0.0063 km/h。关闭 ABS、重置车辆和完成进站服务均清除遗留调节。

六条赛道的 54 圈干地、湿地和单侧积水物理对照原始用时一致。288 条排位参考中，北环干地 Honda e 的一条参考从 1:19.153 变为 1:19.154，其余 287 条显示到毫秒一致。

## 赛中时间差

同一闸口的时间差按穿过阈值的物理步插值得到，供赛中榜单显示。测试覆盖发车、同一闸口先后经过、超车、越界闸口缺失的时间，以及实际一圈差距。

俱乐部杯第一站通过虚拟手柄实跑两圈，首个可比较的时间差为 0.812 秒。独立两圈赛的回放在 63.5 km/h 再现了 19.5% 刹车行程和 4.7% 管路压力。全量回归通过 1,323 项，原生回放通过 33 项。
