# APEX Lab 3.0 Preview 45 套圈、完赛与 60 FPS

## 蓝旗和落后圈数

赛道上以车辆的比赛圈数和实际接近位置辨认套圈。电脑车在有足够宽度和安全间距的直道逐渐让出行车线。16 组四车八圈干湿场景没有重接触、越界或罚时。单车排位的 288 组参考计时在同版本毫秒显示精度内一致。

领跑者完成目标圈数后，其余车辆在下一次经过检查点并过线时结束比赛。先按圈数排位，同圈比较修正后的用时。测试包含同一物理步先后过线、没有依次通过检查点、时间相同，以及长时间停驶后的结算。HUD 蓝旗仅用于提示。

## 实际显示和座舱

在配有 120 Hz 屏幕的 M4 Pro 上，Porsche 911 湿地座舱均衡档运行 45 秒。Metal 回报实际显示 2,700 帧，每秒 60 帧，显示间隔 P95 为 16.7 ms，物理保持 240 Hz。后视镜在行驶中持续更新。独立核对了切回 120 FPS、车库零件经屏幕点选、缩放窗口及截图。

雨后渐干的路面更新耗时与观察到的图像变化分别验证。三个赛道的座舱与赛道机位均在 0.45 秒内平顺过渡，过渡结束的画面与回放直接定位的画面一致。 [Apple 的 Metal 上屏时间接口](https://developer.apple.com/documentation/metal/mtldrawable/presentedtime)
