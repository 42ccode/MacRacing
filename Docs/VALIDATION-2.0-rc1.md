# APEX Lab 2.0 RC1 验证记录

## 自动回归与应用集成

- `./test.sh` 的 441 项检查通过，包括物理、六车六视角、音频、反馈、计时、理想线路、电脑车、传动和维修道。离线音频组使用可访问系统音频服务的进程运行。
- 新回归确认 Porsche 与 Centenario 前轮向路面传递驱动力、后驱 Ferrari 的前轮保持随动。六车的双移线、左右对称性与不同时间步长下的收敛性通过。
- 有效圈按赛道距离记录油门、刹车、转向与速度。测试覆盖输入单位、历史上限、最快曲线保留，以及出界和自动驾驶圈隔离。
- 隔离应用验证 19 项，包括车型间轮胎、辅助、挡位和制动力设定隔离，已装轮胎与待生效设置，版本 8 / 9 存档迁移与备份，换车换图、重载、历史翻页和 1100 × 740 窗口布局。
- ZIP 校验通过，应用内 65 个素材散列与清单一致，签名通过严格校验。独立解压后的 arm64 应用通过启动试跑。发布包仅包含应用、试玩说明与验证记录。

## 本机 Metal 性能

MacBook Pro（Apple M4 Pro，macOS 27.2.1）以 1440 × 900 点窗口运行北环赛道。Centenario 驾驶舱开启实时后视镜，与三辆电脑车混跑，使用自动驾驶隔离实体输入。热身 5 秒后连续采样 300 秒，完成 3 圈、行驶 4.73 km。SceneKit 渲染回调共 27,115 次，平均 90.4 次/秒，帧间隔中位数 9.1 ms，P95 为 17.5 ms。自动驾驶在采样结束时仍运行。

## 正式版验收

- 本机 Xbox 手柄通过蓝牙上报左右转向、LT / RT、A / B / X / Y、Menu、十字键及断连重连。更换为普通 Core Haptics 播放器后，系统创建了左右马达和 LT / RT 通道并启动震动序列。右摇杆环视、游戏内断连自动暂停和实际震感留待游戏内确认。
- 本地包使用临时签名。Developer ID 签名、公证和其他目标设备上的安装验证待完成。
