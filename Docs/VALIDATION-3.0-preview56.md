# APEX Lab 3.0 Preview 56 验证记录

## Porsche 911 方向盘

按 992 原作者模型的轮圈顶点测量转轴。测试扫过 41 组方向盘姿态，旧版在大转角下沿原轮圈法线的最大位移为 167.26 毫米，轮圈中心漂移 11.54 毫米。修正后两项分别低于 0.01 毫米和约 0.02 毫米。方向盘归中时与旧版画面逐字节相同，实况与回放在相同姿态下也生成同一画面。模型由 JK3Dstudios 创作，按 CC BY 4.0 使用。 [驾驶位转角对照](Driving-3.0/preview56-porsche-steering.jpg) · [车型署名](../Assets/Vehicles/README.md)

## 听到旁车的轮胎

两辆车都沿用实录轮胎素材。旁车四轮的接地滑动功率决定响度和声源位置，湿地水膜、离地以及草地会改变沥青轮胎声。回放记录这组读数，摄影机位置决定播放时的声像。

关闭玩家声源和动力声，只在内存里渲染旁车单前轮锁止。距声源 5 米和 45 米时，911 右声道 RMS 分别为 0.01751 和 0.00149，Centenario 分别为 0.01796 和 0.00154。Preview 55 在这四组条件下均为零。交换听者朝向后，主声道随之交换；两车正常滚动接近静音。另行通过草地、车轮离地、回放插值及音量分轨测试。 [轮胎录音署名](../Assets/THIRD-PARTY-NOTICES.md)
