# APEX Lab 3.0 Preview 59 验证记录

## 120 FPS 与输入时序

驾驶时读取输入的目标由 120 Hz 提至 240 Hz，间隔约 4.17 毫秒。车辆仍以 240 Hz 物理步进，车姿按选定的 60 或 120 FPS 呈现。固定每 1/60 秒发布一次新车姿的比赛回放现也遵从所选帧率。本机 Retina 屏幕支持 120 Hz；显示屏刷新、实际渲染帧和设备发来的新输入是三个不同的测量量。

## 键盘微调与反打

方向键持续按下约 0.23 秒达到满量程。反打会先以较快速度回到中心，再向另一侧建立方向。干燥平路上以 100 km/h 松油直行，分别向左右点按 50 毫秒；记录随后半秒的峰值。

| 车辆 | 前轮实际转角，旧 → 新 | 横摆角速度，旧 → 新 |
| --- | ---: | ---: |
| 911 Carrera 4S | 6.15° → 0.38° | 12.34 → 1.26°/s |
| Centenario | 6.15° → 0.38° | 10.19 → 1.05°/s |

另在 60、120、240 Hz 核验长按满舵、反打过中心与左右同时按住。松刹和弯中方向盘实测可按 F8 查看。 [911 弯段](Driving-3.0/preview57-porsche-braking.jpg) · [Centenario 弯段](Driving-3.0/preview57-centenario-braking.jpg)

## 原生验证

同一组 120 次、间隔 1/120 秒的回放输入，60 档完成 60 个不同姿态的离屏绘制，120 档完成 120 个，重复两次结果一致。720 × 405 串行等待 GPU 的离屏测试不能测出实际屏幕持续帧率。独立的 macOS 计时器测得 239.84 次回调/秒，中位间隔 4.157 毫秒；在并发负载下的隐藏原生游戏中，120 档实测每秒 18.3 次主循环读取、231.0 个物理步。短促的键盘刹车在两种显示档位均传到物理步。实体手柄和蓝牙报文频率由玩家另行验收。

关闭牵引力控制的 911 在冷胎湿地全油门起步时仍可能出现过度空转。该极端工况中，仿真的起步离合器会在车轮等效轴速超过发动机后继续传递正向扭矩。默认 TCS 3 的对照未复现同一现象。希望湿地出弯稳定些，可在「设置 → 驾驶」为当前车选择 TCS 3，在「设置 → 手柄」把转向响应改为「细腻」。

冻结源码通过 967 项非手柄回归，另有 46 项原生练习、15 项存档兼容和 12 项驾驶学院检查。所有测试静音。此前的整备质量、窄视野镜面、仪表台裁切和车群音效改进均包含在本版。 [911 驾驶舱裁切对照](Driving-3.0/preview58-porsche-dashboard.jpg) · [双车左镜](Driving-3.0/preview57-narrow-mirrors.jpg)
