# APEX Lab 3.0 Preview 42 单圈排位、维修与赛道机位

## 排位到正赛

单圈排位从计时线前开始滚动。玩家通过起点后计时，完整跑过检查点才能排位。电脑车手使用相同赛道与车辆物理做独立测时。八辆车、六个场地、两种路况的挑战难度参考测时共产生 288 个有效圈。另核对了七场按排位顺序发车的四车短赛，全部完赛且无硬碰撞或越界罚时。

原生验证分别走了跳过排位和虚拟手柄有效圈两条路径，核对发车格、统计隔离和重赛保留发车位。正赛结算按罚时修正，显示最快圈和时间差。

## 赛道和车库

赛中可在维修位停稳后维修，使用原规格轮胎。维修期间玩家保持停车，其他车手继续行驶并计时。正常暂停会冻结比赛和维修时钟。

车库缩略图是已授权车辆的原生 SceneKit 渲染。赛道卡片来自实车正在使用的路线数据。静态赛道机位可跟随一组赛车，保留原来的远近跟车和引擎盖回放视角。湿地喷雾由各轮的实际有效水膜决定，每车最多使用两个发射器。 [第三方资源署名](../Assets/THIRD-PARTY-NOTICES.md)
