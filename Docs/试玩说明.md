# APEX Lab 0.4 — Mac 驾驶模拟原型

解压后，双击 **APEX Lab.app**。支持 Apple Silicon Mac，macOS 14 或以上；不需要安装 Unity。

应用旁会创建 `APEX Lab Data` 保存练习设置、最佳圈和遥测，请将应用保留在可写文件夹中。

## 开始驾驶

开始界面点击 **车内 / 车外** 可直接预览并选择。先在 macOS 中连接 Xbox 手柄，再进入赛道。没有手柄时可以直接使用键盘。

| 操作 | Xbox | 键盘 |
| --- | --- | --- |
| 开始 / 确认 | A / Menu | 回车 |
| 转向 | 左摇杆 | A / D 或左右方向键 |
| 油门 / 刹车 | RT / LT | W / S 或上下方向键 |
| 升挡 / 降挡 | B / X，或 RB / LB | E / Q |
| 切换车内 / 车外 | Y | Tab |
| 车外左右环视（松开回中） | 右摇杆 | 按住 J / L |
| 调整车内视场角 / 座高 | — | [ / ]、Page Up / Page Down |
| 显示或隐藏 HUD / 保存驾驶画面 | — | V / F12 |
| 复位到赛道 | 长按 A | R |
| 暂停 / 继续 | Menu | Esc |

本版修正了左右转向反转。引擎声音使用实录底音，进入驾驶后即可听到怠速，M 切换静音。试玩包中的 12 秒试听使用同一游戏音频链路。

暂停界面可调 ABS、TCS、自动挡、声音、摇杆死区和幽灵车。默认开启驾驶辅助。驶出赛道缓冲区会使本圈无效；复位后按提示回到起点计时。

本版包括约 1.45 公里原创赛道、精细车辆及座舱、四轮独立接地力、车身升沉/俯仰/侧倾、简化轮胎温度、圈速、幽灵车和遥测。仅有前进挡，未实现倒挡/空挡/离合。

当前为尚未实车标定的原型。Xbox 实体手柄输入和震动需实测，60 FPS 为目标而非已测结果。
