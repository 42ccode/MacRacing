# APEX Lab 3.0 Preview 30 展厅几何、灯光与座舱录音

车门、盖板、灯面与固定车身继续使用原 GLB 的三角面。把每块部件实际用到的位置、法线、切线和纹理坐标一起重排，得到更紧的包围盒。逐车检查三角面数量与逐角属性的校验值，并渲染八辆车的开门、驾驶位、左右视线和车尾。

| 展厅车型 | 重排前顶点 | 重排后顶点 |
| --- | ---: | ---: |
| Ferrari 458 | 574,044 | 337,834 |
| Porsche 911 4S | 422,017 | 233,136 |
| Mazda MX-5 | 79,678 | 36,419 |
| Honda e | 717,470 | 310,325 |

这些是场景顶点源的计数，包含部件拆分时出现的重复属性。Honda e 单侧前门的顶点源从 97,220 减至 6,924。展厅原有网格与许可沿用同一份归档。 [车辆模型署名与改动](../Assets/Vehicles/README.md)

固定展厅主灯的投影范围，门、盖板和车轮会在地面投影。Centenario 前轮按作者导出的轮胎最低点对齐地面。座舱视角降低直射光并调整玻璃、金属、塑料的反光。Honda e 在展厅表现为未通电的后视屏，赛道内的电子后视镜由驾驶渲染更新。

458 的中、高转录音段补偿原始录音级别的差异。八车离线音频回归继续检查怠速、加速、换挡、收油、重刹和静音。相同位置的 458 录音，怠速与加速 RMS 分别为 0.129 与 0.149。
