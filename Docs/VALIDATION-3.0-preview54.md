# APEX Lab 3.0 Preview 54 验证记录

## 进站避让

对手开始转向进站时，如果前车处于它即将经过的路线上，便根据纵向间隔与前车速度限制进站速度。在入口分流区，这项观察会持续到维修道限速线。并排和后方的车不触发该限制。

六条赛道共 72 组干湿地四车对照。24 组在进站路径上安排不同车速的慢车，新版消除了原来的 29 次早期车车接触和 3 次后续护栏接触，24 组全场均完赛，22 组完成换胎。另 48 组安排前车偏离进站路线、在后方或路径畅通，车辆轨迹与原有输出逐项一致。

## 理想线路显示

按赛道位置复用路面标记的顶点和材质，车速改变时仍重新计算制动、收油和加速提示。六条赛道各检查 820 个位置，并检查入维修道、倒车、隐藏提示与回放切换。对照的顶点、索引与颜色数据一致。每条赛道停车时连续 200 次显示更新都复用了原几何。

第二圈的线路显示更新耗时 P95 在高原高速环从 0.0408 ms 降至 0.0082 ms，在河谷环线从 0.0379 ms 降至 0.0087 ms。测量仅覆盖显示线路的更新函数。
