# APEX Lab 3.0 Preview 3 验证

本版面向 Apple Silicon、macOS 14 或以上。验收使用独立的测试数据，不改写现有玩家练习数据。521 项 Swift 检查、32 项原生练习检查和 81 项原生界面检查通过。

- Swift 全套检查覆盖物理、制动、车型和赛道、音频、反馈、输入、计时和遥测。
- 原生应用检查覆盖旧练习存档兼容、最佳圈隔离、维修、遥测对照和分析光标。界面检查包含 900×664 和 1280×800 窗口、键盘事件、焦点和确认、设置持久化及写入失败、实际座舱预览、仪表布局保存和取消、待安装轮胎与短赛中换胎限制、短赛倒计时与暂停。
- [原生截图](Driving-3.0/README.md)包括开始界面、座舱预览、制动曲线和驾驶仪表。

本轮主要改进交互与显示。曲线来自现有驾驶计算，物理与输入频率未在本轮重新调校。实体 Xbox 的蓝牙震动和实际驾驶手感留给玩家验收。
