# APEX Lab 3.0 Preview 38 驾驶与赛道

## 六条赛道

湿地参考线在同一弯道上分别估计左右轮迹的水深，对更深的一侧赋予更高权重。线路在避水时保留赛道边缘余量，并在提前几十米内逐渐改变方向。水深来自赛道接地和渲染共用的静态水膜分布。六条赛道的参考线加权平均水深降低约 4% 至 7%，最大横向改线 1.14 米。六场干地和六场湿地四车两圈短赛均有完赛、碰撞与越界检查。 [iRacing 湿地驾驶说明](https://www.iracing.com/weather/)

胎面在沥青、彩绘路肩和草地之间按实际覆盖平滑混合。台架模拟让 MX-5 在相同深度的水膜上使用雨胎，从 108 km/h 开始制动。沥青、接缝和彩绘路肩的停车距离分别为 54.6、59.0 和 64.5 米。摩擦系数是模拟标定。 [FIA 赛道标线涂料标准](https://www.fia.com/sites/default/files/fia_standard_3503-2019_paints_for_motor_racing_circuits_1.pdf)

河谷环线加入坡度和横坡后使用独立圈速。原生测试用旧版平地练习存档启动应用并修改一项设置，验证旧圈速、幽灵车和踏板分析仍保存在存档中。

## 八辆车

车辆物理固定以 240 Hz 更新，每步三个轮胎与悬架子步。ABS 每秒采样 120 次，制动扳机、兼容握把和座舱声音都随卸压与回压变化。八车台架从 100 km/h 制动到 4 km/h，在本次胎温设置下，干地停车距离为 37.4 至 39.6 米，0.60 mm 水膜上使用雨胎时为 45.6 至 48.9 米。实体 Xbox 蓝牙震动留待游戏内验证。
