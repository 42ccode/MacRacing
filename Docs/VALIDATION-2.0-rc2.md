# APEX Lab 2.0 RC2 验证记录

## 座舱与车外

- 使用 Metal 原生渲染复核六车的驾驶舱、仪表台和近距跟车画面。Mazda 保留原车仪表视野，Centenario 原仪表框内显示速度、挡位与转速，Porsche 和 BMW 使用各自的原型仪表台。
- 六视角、车轮与卡钳、前方视线、环视与回正通过自动检查。

## 操控对照

六款车从 108 km/h、三挡开始，固定输入持续 0.5 秒。下列数值为实验模型的仿真结果。

| 项目 | RC1 | RC2 |
| --- | ---: | ---: |
| 20% 转向、15% 油门时的横向加速度（六车范围） | 0.34–0.42 g | 0.24–0.30 g |
| 65% 转向、15% 油门时的横向加速度（六车范围） | 0.74–0.82 g | 0.73–0.81 g |
| Mazda 25% 刹车时的减速度 | 0.71 g | 0.53 g |
| 4.9% 与 5.1% 油门之间的纵向加速度差（六车范围） | 0.023–0.048 g | 约 0.001 g |

446 项自动检查通过，涵盖全刹、双移线、低速回正、倒挡、轮胎、离线音频、电脑车、计时和维修道。实际手柄驾驶手感留待试玩确认。发布包使用本地临时签名。
