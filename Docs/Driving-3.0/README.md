# APEX Lab 3.0 界面实机截图

使用 macOS 下的 SceneKit / Metal 原生验收应用，在 900×664 点窗口中绘制。为减小发布包体积，截图缩至 1200 像素宽并转成 JPEG。

- [开始界面](start.jpg)：车辆与赛道选择、练习和短赛入口。
- [制动响应](brake-response.jpg)：三种曲线和半行程目标压力。
- [座舱预览](seat-preview.jpg)：暂停时在真实车内调整垂直视野和座高。
- [精简仪表](compact-hud.jpg)：驾驶中的车速、挡位、转速和踏板。

车辆模型署名见 [车辆资源说明](../../Assets/Vehicles/README.md)，随应用资源附带。
