# APEX Lab 3.0 Preview 37 路肩与驾驶验证

四个车轮独立计算接地面覆盖的沥青、彩绘路肩和草地比例。接地面跨过边缘时，随着覆盖比例连续混合抓地力。路肩组织、坡形和表面仍取自对应赛道的视觉位置。彩绘摩擦下降幅度是模拟标定。

在隔离材质影响的台架测试中，MX-5 使用雨胎，从 108 km/h 开始全力制动，路面水膜为 0.55 mm。全胎面接触沥青、胎面跨过接缝和全胎面接触彩绘路肩的停车距离分别为 54.6、59.0、64.5 米。

六条赛道的干地和湿地均覆盖四车两圈短赛。河谷环线纵坡、横坡、赛道边缘、湿地积水和护栏与车辆模型联动。方向盘与踏板手感仍需玩家实驾评价，实体 Xbox 蓝牙震动留待游戏内确认。

车辆的前后轮使用各自的旋转惯量。游戏每秒固定计算 240 次，每次三个车胎与悬架子步。ABS 每秒采样 120 次，握把和制动声音随各轮卸压与回压变化。可试听 [八车座舱音频](Audio-3.0/Eight-car-audio-tour.wav) 和 [MX-5 负载过渡](Audio-3.0/MX5-load-transitions.wav)。 [第三方资源署名](../Assets/THIRD-PARTY-NOTICES.md)
