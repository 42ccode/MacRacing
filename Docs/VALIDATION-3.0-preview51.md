# APEX Lab 3.0 Preview 51 验证记录

## 原装 E30 仪表

BMW E30 的原仪表贴图按车速和转速独立转动指针。38 张静音离屏截图覆盖干湿赛道、原地拉转、归零与超量程。80 km/h、3,300 rpm 与 154 km/h、6,550 rpm 的读数对照了原刻度。跟车视角对照逐像素一致。正常驾驶位仍可见真实方向盘遮挡部分低位刻度。

## 比赛与湿地声音

六条赛道合计 72 组四车干湿地对照中，28 组严重故障场景提前 72.16–150.20 秒结算退赛。健康车辆轨迹和成绩保持一致。退赛要求比赛已进入终点阶段、玩家已结算并完成滑行、其余在赛对手均严重受损并连续停在赛道及维修区外。黄旗单独按车身边界判断遮挡。

对手甩水使用同一段 CC0 湿沥青录音，各车独立播放。三组高速近距离超车离线测得甩水声左右差 12.8–13.5 dB，干地输出与基线逐样本一致。[素材与授权](../Assets/THIRD-PARTY-NOTICES.md)

## 静音验证

1,257 项非手柄回归以及 149 项额外原生检查通过。原生检查覆盖菜单、视区、存档恢复、进站、渐干和一场从发车持续到结算、回放与重载的自动驾驶比赛。测试输出静音。F11 新增优先震动通道选择，实体 Xbox 蓝牙震动体验留待玩家验收。
