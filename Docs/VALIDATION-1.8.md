# APEX Lab 1.8 验证记录

`./test.sh` 共 342 项通过。新车检查覆盖实际轮胎网格滚动轴线、轮心和物理接地点、卡钳固定、六种视角和连续变道。六张赛道检查路面边界、起终点、分段计时、理想线路及四车混跑。额外模拟在五车六图的 30 个组合中各完成一个自动驾驶圈。

专用诊断应用执行了 14 项实际 HUD 集成检查。通过 F6 打开编辑时冻结车辆，独立拖动八个面板，恢复默认，保存后继续驾驶，重新加载布局，调整窗口尺寸保持面板在屏幕内，以及从暂停界面编辑后返回暂停。编辑图为实际 HUD 输出，车辆和赛道画面由原生渲染器生成。见 [1.8 预览](Driving-1.8/README.md)。

两辆车的原始 GLB 包含作者、来源和 CC BY 4.0 标记。模型来源及导入前后哈希见 [车辆署名](../Assets/Vehicles/README.md)。BMW 采用简化座舱，Mazda 保留原模型座舱并校正眼点。新车使用实验后驱参数，新赛道为原创平面干地布局。

本地设置保存 HUD 位置。30 组个人最佳沿用各自的车和赛道 ID。硬件手柄及目标设备性能仍待实测。
