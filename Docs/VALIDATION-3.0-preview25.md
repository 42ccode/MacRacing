# APEX Lab 3.0 Preview 25 座舱音效

试听由游戏的车辆物理与 Core Audio 离线渲染，使用默认混音音量。两段均为 44.1 kHz、16 位立体声。

| 试听 | 工况 |
| --- | --- |
| [MX-5 座舱，13 秒](Audio-3.0/MX5-load-transitions.wav) | 0.5 秒空挡补油，3 秒起步加速，4.62 秒升挡，7.30 秒收油，8.35 秒重新给油，9.90 秒带刹降挡，10.50 秒重刹。峰值 0.631。 |
| [八车对比，64 秒](Audio-3.0/Eight-car-audio-tour.wav) | 每车 8 秒，包含停车、加速、升挡或电机持续加速、收油与带刹入弯。顺序为 Concept GT、Ferrari、Porsche、BMW、Mazda、Lamborghini、Lotus、Honda。峰值 0.659。 |

座舱分别混合空气传入的发动机声和车身传入的低频。给油时进气、输出扭矩分别建立。升挡时点火与扭矩下降，车轮和曲轴继续转，恢复扭矩时座舱低频随负载回升。收油后高频随进气和燃烧贡献减弱，车轮带动曲轴时会留下较低沉的声音。降挡的音高随物理引擎的转速变化。座舱空气与车身传播是模拟参数。 [SAE 车辆座舱声学传递路径研究](https://saemobilus.sae.org/papers/interior-noise-simulation-improved-vehicle-sound-2001-01-1539)

对七辆燃油车固定 3500 rpm，分别渲染换挡与维持负载。换挡切火期间保持 80% 油门。以同一采样时段的维持负载组为基准，切火时波形均方根为基准的 43%–68%，扭矩恢复后约为 100%，收油反拖后为 30%–69%。实际驾驶还会出现换挡时的转速变化。Honda e 为单速驱动，座舱低频跟随电机轴速与实际驱动负载。

在相同的 4400 rpm 电机轴速下，Honda e 模拟座舱内的动力声均方根为带载 0.043、滑行 0.008。全部回归通过，包含 40 项音频检查，以及另行跑过的 39 项原生应用检查。

音色基于已授权录音，部分车型使用同系或相近的车辆。混音的低频、进气响应和反拖强度尚缺对应实车座舱与扭矩记录标定。 [录音出处和许可](../Assets/THIRD-PARTY-NOTICES.md)
