# APEX Lab 3.0 Preview 40 驾驶、赛道与加载

## 发车并线

在 Centenario 干地短赛中，部分 AI 车手从错位发车格提前合流，强动力加速时出现持续摆动。新版根据转弯所需侧向加速度、已发生的车身侧滑和并线幅度限制油门。靠近参考线且车身稳定时归还油门余量。修正后，Centenario 在六条赛道的干地和湿地四车两圈测试中均完成比赛，且无硬碰撞与越界罚时。

## 场景加载

启动先读取本地练习存档，再构建对应赛道、路况与车辆。切换赛道或路况直接载入选择的车型。以 Porsche 911 和湿地河谷存档交替运行两组前后测试，每组连续打开六次。预热后的重新打开中，场景初始化约从 0.40 秒降至 0.16 秒。测试同时检查镜面、驾驶视角参数和原有圈速的恢复。

## 驾驶与赛道

车辆物理固定以 240 Hz 更新，每步三个轮胎与悬架子步。ABS 以 120 Hz 采样，各轮的卸压与回压驱动制动扳机、兼容握把和座舱声音。八辆车的前后轮分别使用对应惯量。

六条赛道覆盖四车两圈干湿地短赛。湿地参考线比较左右轮迹的水深，六条赛道平均减少 4% 至 7% 的加权水深。相同水膜下，MX-5 雨胎从 108 km/h 在沥青、接缝及彩绘路肩全力制动，模拟停车距离分别为 54.6、59.0、64.5 米。河谷环线增加坡度后单独计时，原平地圈速、幽灵车和练习分析仍保存在本地存档。 [iRacing 湿地说明](https://www.iracing.com/weather/) · [FIA 赛道标线涂料标准](https://www.fia.com/sites/default/files/fia_standard_3503-2019_paints_for_motor_racing_circuits_1.pdf)

八辆车均可在展厅开门，驾驶位逐车验证后视镜。动载、换挡、收油、轮胎擦滑和制动阀声均按驾驶工况混音。实体 Xbox 蓝牙震动留待游戏内验证。 [八车试听](Audio-3.0/Eight-car-audio-tour.wav) · [MX-5 负载过渡](Audio-3.0/MX5-load-transitions.wav) · [第三方资源署名](../Assets/THIRD-PARTY-NOTICES.md)
