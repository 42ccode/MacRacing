# APEX Lab 3.0 Preview 5 验证

在原有界面中统一低制动压力的标定、实际压力和辅助驾驶反算。键盘踏板支持短按控制部分行程。手柄仍使用模拟扳机行程。

108 km/h 开始全制动，减速至 28.8 km/h。暖胎、干地、ABS 5 档的模拟台架距离如下。

| 车型 | Preview 4 | Preview 5 |
| --- | ---: | ---: |
| Mazda MX-5 | 46.7 m | 43.3 m |
| Porsche 911 4S | 49.1 m | 44.9 m |
| Lamborghini Centenario | 49.1 m | 44.4 m |

三车在上述干地对照中均未达到测试定义的锁止阈值。在一侧为草地的对照中，ABS 3 档的峰值偏航率降低约 3% 至 4%，距离多约 0.8 至 1.4 米。这是稳定性与制动距离的取舍。

六图约 104 万次赛道投影微基准，耗时从约 0.206 秒降到 0.054 秒，校验和一致。30 秒座舱全场景单次对照，绘制回调平均 116.0 → 119.9 FPS，p99 间隔 17.9 → 12.4 ms。后者包含整机调度波动，不能代表每台设备。

532 项完整套件检查、额外的干地高档 ABS 检查、32 项原生练习回归与 81 项菜单检查通过。
