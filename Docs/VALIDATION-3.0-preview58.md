## 圈速、练习分析与幽灵

911 新车重建立独立的个人最佳与幽灵。在「驾驶记录 → 练习最佳圈」选择 911，如果当前干湿设置下有旧成绩，可按「查看旧车重成绩」查看原纪录和三个分段。切回新成绩即可继续比较。加载并重写旧存档时保留原 911 圈速、幽灵、练习分析及已退役车辆的记录。Centenario 沿用原有个人最佳。验证使用隔离存档。

## 短时掉帧

物理仍以 240 Hz 步进，每次最多补算 24 步。对 95 毫秒的卡顿，旧版在该段少推进 28.33 毫秒，现版剩余约 3.33 毫秒由下一步消化。晚到的制动只作用于新输入覆盖的末段。超过或等于半秒的中断会重新建立时间基准，暂停、失焦及进站恢复首帧保持车姿。30、60、120 Hz 时序测试都精确推进 1 秒。四车 15 秒对照在正常帧率下沿相同轨迹行驶。

240 Hz 四车求解的普通回调线程 CPU 中位数为 0.0956 → 0.0960 毫秒。95 毫秒卡顿的恢复帧为 0.723 → 1.032 毫秒。持续低帧率时限制单次补算量。另以 12 秒原生维修验证暂停首帧不改变位置或刹车温度，比赛遥测持续按模拟时间每 0.1 秒记录一行。

## 同转速车群的引擎声

同款车分别使用独立、稳定的录音起点。将三辆 911 或三辆 Centenario 置于相同位置和转速，对各声源做离线隔离渲染。原先每一对怠速波形的相关系数都是 1.000，三车一起响时同一波形被重复叠加。改后，911 三组系数为 0.211、−0.331、0.330，Centenario 为 0.010、0.067、0.032。3000 转带负荷时，各对声源的相关系数绝对值均低于 0.38。录音音高仍由各车模拟引擎转速决定。使用的素材及来源见 [录音署名](../Assets/THIRD-PARTY-NOTICES.md)。

## 从驾驶位复查

Preview 57 引入的 F8 弯段视图、两车侧镜和松刹时接地橡胶的渐进释放均随本版提供。按 F8，将光标移到刹车图上再放大，可读取同一位置的踏板、液压和方向盘角度。 [911 北环实测](Driving-3.0/preview57-porsche-braking.jpg) · [Centenario 北环实测](Driving-3.0/preview57-centenario-braking.jpg) · [双车窄视野左镜](Driving-3.0/preview57-narrow-mirrors.jpg)

911 在高原赛道约 86 km/h、4.78° 车身侧倾、最低座位向右看时，旧 60 毫米近裁面会切穿仪表台。驾驶舱近裁面改为 15 毫米，42°、62° 和 84° 三种视野均恢复完整原车表面。正常直行复查了连续 29 个原生画面。 [仪表台前后对照](Driving-3.0/preview58-porsche-dashboard.jpg)

固定赛道机位也会按车辆相对速度更新轮胎滚动、擦地和甩水录音的音高。保持轮胎状态一致，分别以接近、平行和远离三种速度渲染同一段擦地声，正向穿零数从原来的 545 / 545 / 545 变为 619 / 545 / 490。驾驶位的相对速度系数为 1。

956 项非手柄回归、46 项原生练习和 15 项存档兼容检查通过。全部使用隔离测试数据，游戏声音仅在内存中渲染。
