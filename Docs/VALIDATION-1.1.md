# APEX Lab 1.1 验证记录

## 自动检查

`./test.sh` 完成，退出码 0，共 72 项通过，无失败；包含原有动力学、轮胎与车损、十分钟模拟耐久、模型、相机和音频回归。

新增检查覆盖：

- 车身中心尚在沥青上时，正确识别驾驶员左侧车轮压路肩；只有接触一侧产生路肩激励，悬挂压缩量相应改变。
- 停在路肩上不产生持续震动；路肩区段结束后停止接触判定，返回沥青后反馈衰减。
- 加速时纵向 G 为正、后悬挂更压缩；制动时纵向 G 为负、前悬挂更压缩；右转时驾驶员坐标横向 G 为正。
- 轮胎采样点跟随车身航向，并保持正确轮距与轴距。
- 实际 AVAudioEngine 离线链路的路肩音效改变输出且不削波；静音与暂停时包含路肩音效在内的输出归零。综合音频峰值约 0.450。

## 原生界面检查

在原生应用中用键盘驾驶，检查车内与车外视角的四轮图示、温度/压力/胎面余量、四角弹簧与 mm/kN 数值、G 表和路肩强度条。右侧面板与下方圈速表分开，文字与图示显示正常。驾驶后的悬挂读数及 G 轨迹更新。

路肩接触、反馈衰减和 G 方向由确定性自动检查验证；没有以人工跑完整赛道或实体 Xbox 手柄体验代替这些检查。

## 范围与限制

弹簧图示来自当前四角弹簧阻尼模型，显示相对静态车高的行程；模型没有独立非簧载质量、完整悬架几何或实车标定。路肩音效是程序合成，反馈不等同于方向盘力反馈。CSV 保留模型坐标的 lateral_g（正值向左），界面转为驾驶员坐标（正值向右）。

实体 Xbox 输入及震动手感仍待实测，60 FPS 为目标值，未做本版性能基准测试。发布包使用本地临时签名，尚未做 Developer ID 公证。
