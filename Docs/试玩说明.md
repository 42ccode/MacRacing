# APEX Lab 3.0 Preview 21 — Mac 驾驶模拟

解压后，双击 **APEX Lab.app**。支持 Apple Silicon Mac，macOS 14 或以上；不需要安装 Unity。

练习数据优先写到应用旁的 `APEX Lab Data`。该位置不可写时使用 `~/Library/Application Support/APEX Lab`。

先试 MX-5：开始或暂停时按 F11，转向选「细腻」，刹车选「长行程」；按 F9 可切换湿地，按 F8 可看练习分析，F10 可进入两圈短赛。

试带刹入弯时，可用同一个干地弯角重复两次，保持近似的入弯速度和转向量。第一次快速松刹，第二次缓慢松开，留意车头开始收紧路线的时机，以及手柄前轮擦滑提示的变化。

维修道内会显示距离限速区的米数。开启限速辅助时，车辆逐步靠近 60 km/h。短赛持续超速会计入罚时。画质可在「画面 → 画质档位」选择性能、均衡或画质。

## 车辆外观与后视镜

Porsche 911 Carrera 4S 换用 JK3Dstudios 的 992 Aerokit 车身与完整内饰，恢复座舱和仪表台视角。新增 Lotus Elise 和 Honda e，两辆车也带原作者座舱。Honda e 使用单速驱动，车内可看到左右电子后视镜与中央后视屏。

在座舱内拨右摇杆或按 J / L 看向外镜。实时车速和挡位仍可用界面上的驾驶仪表查看。

## 3.0 驾驶手感

- 在干地直道从轻触 LT 逐步踩到深刹，再带少量刹车入弯。轻触压力更缓，重踩更快建立压力，完全松开后会迅速卸压。
- 可在同一条直道对比「标准」和「细腻」，再用同一弯道对比「渐进」和「长行程」。F8 可对照有效圈中的扳机行程和制动压力。
- 按 F11 可测试手柄震动。实驾中可用同一条路肩比较路肩和光滑路面，再试重刹触发 ABS。
- 在湿地弯中加油时，牵引力控制随轮胎的侧向负荷介入，扭矩会逐步恢复。带载锁胎、轮胎平斑、路肩和限扭有各自的震动节奏。
- 完成有效圈后，幽灵车从下一次计时开始时播放。与玩家车辆重叠时会淡出。短赛中四轮持续越界 1.5 秒会加罚 2 秒。

## 3.0 预览版界面

- 开始界面点车辆、赛道直接选择；「进入练习」和「两圈短赛」各有入口。
- 点击「设置」或按 **⌘,**。各页设定会保存，手柄校准也可以用 F11 打开。
- 到「画面 → 座舱预览」边看前挡风玻璃边调视野和座高。按 Esc 或 B 完成，原驾驶视角保持不变。
- 到「手柄 → 制动响应 / 转向响应」查各档的曲线及半行程输出。恢复默认值只影响对应分类，需要确认。
- 到「驾驶」可直接选下次装的轮胎，查看已装配方和冷压；重开或进站换胎后生效。
- 新安装默认精简仪表。按 F7 在完整与精简之间切换，按 F6 调整面板位置。编辑中按 F6 保存，Esc / B 放弃本次修改。
- 菜单用方向键 / Xbox 十字键移动，回车 / A 确认，Esc / B 返回。Tab / Shift+Tab 或 RB / LB 可逐项移动。
- F8 分析页可用鼠标或左右键定位赛道位置，比较对应的车速、刹车行程和制动压力。

## 2.0 的变化

2.0 RC24 的短赛倒计时和绿灯带有不同提示音。

2.0 RC23 护栏擦碰按接触方向减速，浅角擦碰保留大部分沿栏速度。

2.0 RC22 高速跟车时有尾流。正后方阻力和前轴下压力会下降，移出后恢复。

2.0 RC21 在 F8 中显示新圈的制动压力虚线。CSV 追加整场时间和各轮制动数据。

2.0 RC20 平滑玩家车、悬挂和视角在物理步之间的移动。

2.0 RC19 可在 F11 选择标准、细腻或灵敏转向。细腻档适合高速小幅修方向，打满仍保留全部转向。

2.0 RC18 优化轮速求解，为场景更新和手柄读取留出更多计算时间。

2.0 RC17 可分别查看每条轮胎的内、中、外胎温。

2.0 RC16 的湿地会出现浅水线和较深的积水；同一弯的内外侧抓地可以不同。

2.0 RC15 的干地短赛中，电脑车会在足够长的直道找空位超车。

2.0 RC14 让 MX-5 原仪表的车速、转速和水温针跟随实际状态。

2.0 RC13 可按车型选择渐进、长行程和短行程。驾驶踏板图用红线显示刹车行程，橙线显示管路压力，黄色表示 ABS 介入。

2.0 RC12 可在开始或暂停菜单按 F11 对照摇杆原始值、死区处理、LT / RT 和游戏读取间隔，并在同页测试震动。

2.0 RC11 加入各车型的发动机声和电脑车立体声。使用耳机时，可以听到电脑车从哪一侧接近。

2.0 RC10 的高原高速环加入 33 米高差和带横坡弯道。上下坡会改变滑行和制动，坡道版单独计时。

2.0 RC9 可在开始或暂停时按 F10 进入两圈短赛。绿灯起步，完成两圈后按 Esc 查看名次与罚时。短赛遥测写入 `latest-sprint.csv`。

2.0 RC8 更新 Mazda MX-5 的动力曲线、六挡齿比和换挡提示。

2.0 RC7 加入湿地轮胎水雾和水声。混跑时可通过电脑车的刹车灯提前判断减速。

2.0 RC6 可以在开始或暂停时按 F9 切换干地与湿地。湿地可在轮胎选项选雨胎，再重开或进站更换。干地和湿地分别保存个人最佳。车辆压草后胎面会短暂带泥，偏置碰撞会让车辆产生偏航。

2.0 RC5 加入各车型的前后轴气动平衡和轮胎擦地声。路面温度影响胎温，遥测可查看偏航、前后轴下压力和四轮抓地利用率。

2.0 RC4 将手柄读取和场景更新目标提高到 120 Hz，柔化摇杆越过死区后的起转。轮胎力随滚动距离建立，单轮跨到草地边缘时抓地力逐步下降。

2.0 RC3 扩大了 LT 前半程的轻刹控制区间，后半程逐步加重制动。踏板图显示输入行程，旁边显示制动压力。Xbox 蓝牙优先用握把兼容通道，在暂停菜单点击「测试手柄震动」可播放四次短震。

2.0 RC2 调整了座舱视点、材质、仪表和近距跟车。Centenario 的仪表显示实时读数，Mazda 保留原仪表视野。高速轻推摇杆、轻踩刹车和收油的响应更平顺。

暂停菜单可按车型设置轮胎、ABS、TCS、挡位模式和前轴制动力分配。轮胎在维修换胎或新一场练习时安装。Porsche 911 4S 和 Centenario 使用实验四驱。

按 F8 打开练习分析。完成一个手动有效圈后，面板会显示油门、刹车、转向、速度和三段用时。比较对象是当前车图组合最近的有效圈和最快的有遥测圈。历史最多保存 20 圈。旧版最佳圈和幽灵车仍可使用，旧存档在首次保存前备份。

## Xbox 手柄验收

1. 蓝牙连接手柄后，按 A 进入赛道，检查左摇杆、RT 油门、LT 刹车，以及手动挡的 B / X 换挡。
2. 按 Y 切到驾驶舱，左右拨动右摇杆，观察视线方向和松手回正。
3. 按 Menu 暂停，将震动强度调到 75% 或 100%，点击「测试手柄震动」。兼容模式下四次短震都通过握把播放，界面会显示当前输出模式。
4. 继续驾驶后关闭手柄，确认游戏暂停。重连后确认仍停在暂停界面，再手动继续驾驶。

## 历次更新中的操作

新增 SDC PERFORMANCE 的 Lamborghini Centenario。车身、门板、座椅、方向盘和仪表都来自同一完整授权模型。新安装默认选中，已有配置可在开始或暂停菜单用 C 或 Xbox 十字键左右换车。HUD 提供实时速度、挡位和踏板读数。

更新了赛道铺装、磨耗标线、胎痕、起终点棋盘格和维修楼细节。按 F7 可在完整与精简 HUD 间切换，精简模式保留后视镜、小地图、圈时、分段与踏板条。F6 仍可移动全部仪表。仪表模式和位置会自动保存。

驾驶舱默认开启车身镜面反射和虚拟后视镜。虚拟镜框哪一侧亮黄灯，就表示该侧有电脑车接近。按 B 或在「显示辅助 → 后视镜」切换。Xbox 右摇杆向左或向右推可以转头观察，键盘用 J / L。松手后视线回正。

六张赛道均有可驾驶维修道。在起终点前从行车方向右侧的 PIT IN 进入，沿蓝色边线开到 BOX 黄框。白线之间限速 60 km/h。限速器默认开启，可按 K 或点击输入条上方的开关切换，设置会保存。

在黄框内停稳后，按 P 或 Xbox 十字键 ↓ 开始 12 秒修车换胎。暂停会冻结倒计时。车辆无法自行进站时，按 Shift+P 或使用暂停菜单「拖车维修」。完成后按 E 或 Xbox B / RB 挂入 1 挡，从 PIT OUT 并回主赛道。出场圈不参与个人最佳，下一次正向越过主赛道起终点后开始计时。

倒车时先接近静止，松开油门并踩住刹车。按 Q 或 Xbox X / LB 进入 N，等挡位显示 N 后再按一次进入 R。松开刹车用油门倒车。停车后踩住刹车，按 E 或 B / RB 依次回 N 和 1。

车况面板新增前轴制动力分配。键盘 4 / 5、驾驶中的 Xbox 十字键左右、面板减号 / 加号均可调整。每次 0.5 个百分点，各车型独立保存。

进入赛道后按 F6，或点击暂停菜单「布局编辑」。鼠标可拖动九个描边面板，包括虚拟后视镜。点击「保存布局」或再按 F6 完成，可用「恢复默认」重新摆放。编辑时练习暂停，窗口大小变化后面板仍保持在屏幕内。

新增 BMW M3 E30、Mazda MX-5、高原高速环（2.40 km）和河谷环线（1.82 km）。在开始或暂停菜单按 C 换车、N 换赛道，Xbox 可用十字键切换。

开始或暂停菜单用 O 或「电脑对手」选择 0–3 辆。蓝、橙、绿色车辆会用不同节奏沿赛道行驶，前方有车时减速。小地图上的同色点表示电脑车位置。车辆接触会产生碰撞响应，较重接触会计入玩家车损及兼容手柄反馈。

按 U、Xbox 右摇杆按下或菜单「自动驾驶」可切换。自动驾驶接管油门、刹车、转向和换挡，操作踏板或转向即可接回。开启前请让车辆面向赛道方向。自动驾驶圈不计入个人最佳，对手数量会保存，自动驾驶在每次启动时关闭。

理想线路默认开启。绿色提示加速，黄色提示收油，红色提示制动。按 I、Xbox 左摇杆按下，或使用暂停菜单「理想线路」切换。左下角速度采用赛道曲率和统一干地参数估算，可作为练习参考。

1.6 顶部新增圈速差和三段计时。先完成一个有效圈建立参考；之后负值表示在同一赛道位置比个人最佳更快，正值表示更慢。S1 / S2 是小地图中的分段点，S3 在终点完成。面板标明本圈 / 上圈分段；无效圈、出场圈和没有参考时不显示差值。

换车或换图会保存原组合、恢复目标组合的最佳圈及幽灵车，退出后仍保留。六车六图共 36 组个人记录；辅助和轮胎方案暂不另外区分。出界、持续逆行、跳过检查点会令本圈无效，不能刷新最佳。复位到起点以外需先通过起点。首次从 1.5.x 升级会保留偏好并清除一次旧圈时。

输入横条增加八段转速提示，随转速从绿色到黄色、红色点亮，帮助手动换挡。

1.5.2 左下角改为截图风格的横向驾驶输入条。从左到右是最近 5 秒的输入曲线、LT 刹车 / RT 油门实时柱、挡位、车速和动态方向盘。绿线为油门，红线为刹车，ABS 介入时刹车段显示黄色。曲线从右向左滚动，暂停或维修时冻结，复位 / 换车 / 换图 / 重开时清空。方向盘指示左摇杆 / 键盘转向输入，不代表方向盘力反馈。按 V 隐藏 / 显示。

新增防倾杆、悬挂缓冲、刹车热衰减；左侧车况面板显示刹车温度与可用制动力。路肩采用与物理共用的立体轮廓，赛道增加看台、标柱和维修物件，Porsche 座舱增加动态指针仪表。

Xbox One 蓝牙连接后，开始驾驶并按 Menu / Esc 暂停，点击「测试手柄震动」。测试依次播放左、右、刹车、油门四段短脉冲；缺少扳机能力时折算到对应手柄马达。菜单显示 macOS 实际开放的反馈能力，强度可按 0 / 25 / 50 / 75 / 100% 循环调整，默认 75%。若显示不可用，驾驶输入仍可使用，程序不会假报震动已经生效。

行驶时压路肩、草地、打滑、ABS 与碰撞会触发不同反馈。暂停、失焦、断连及维修停止行驶反馈；暂停菜单的测试为手动短时例外。物理参数未经实车标定，本版保留设置并重置旧最佳圈和幽灵车。

## 轮胎、车损和维修

右侧四轮图示按驾驶员左右排列，查看温度、压力、剩余胎面、接地路面和爆胎状态；底部显示最大部件损伤和水温。冷胎、过热、胎压偏离、磨耗和爆胎都会改变抓地力；悬架碰撞损伤会造成跑偏，车头损伤会影响散热和动力。

暂停菜单选择软 / 中 / 硬胎、调整冷胎压，下一次维修或重新开始时生效。冷胎压基准为 26°C，新胎为 38°C，仪表显示的当前压力会略高于冷压设置。软胎抓地较高但磨损较快。

进站与维修保留此前的个人最佳。R 复位保留损伤和轮胎状态。选择「重新开始」可用完好车辆开启新练习。

车身前后部有简化变形，尾翼和轮胎外观随损伤变化；目前没有零件脱落、玻璃破碎或软体碰撞求解。

## 车辆与视角

Y / Tab 依次切换驾驶舱、仪表台、引擎盖、保险杠、近距跟车和远距跟车。仪表台视角隐藏方向盘，跟车视角可以环视。暂停或开始界面使用十字键左右、C 或界面箭头换车；换车会重开练习、保存原组合并恢复目标组合的最佳圈和幽灵车，车辆选择自动保存。

Ferrari 458 模型带原作者提供的详细座舱。Porsche 911 Carrera 4S 已改用 992 的外观和完整内饰。各车采用独立的实验动力、传动和悬挂预设。Porsche 和 Centenario 使用实验四驱，其余使用后驱。

## 悬挂、G 值和路肩

四根弹簧随实际悬挂状态变化，正值表示相对静态车高压缩、负值表示伸张，单位 mm；下方为当前轮载 kN。加速时后悬挂压缩，制动时前悬挂压缩，转弯时两侧随载荷转移变化。

G 表外圈为 2 G，横向向右为正、纵向加速为正，轨迹保留约 1.5 秒。超出外圈时数值继续显示，光点限制在圆周。

压上路肩的轮胎和悬挂变为橙色，并显示反馈强度；颠簸声和兼容手柄的震动随车速及接触激励变化。停在路肩上不会持续震动。按 V 可以隐藏整个仪表。
