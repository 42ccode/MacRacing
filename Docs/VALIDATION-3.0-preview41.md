# APEX Lab 3.0 Preview 41 比赛、巡回赛与驾驶学院

本地练习、可配置比赛、三杯巡回赛和驾驶训练共用八辆车的操控、六条赛道和干湿地接地模型。显示和输入保留原有设置，巡回赛与课程结束后恢复车库的练习选择。

## 比赛

支持 2、3、5、8 圈及三档难度。正式名次用完赛时间加罚时排序。过线后自动驾驶进入减速段，结算页可打开赛末回放、重赛或返回选择。回放以 20 Hz 保留最多 90 秒的四车姿态，支持 0.5×、1×、2× 播放。自动驾驶使用情况会随成绩写入记录。

回归包含从杆位和末位起步的专项场景，以及 5 圈和 8 圈的四车长赛。发车灯有低位同步指示，适配八辆车的座舱视角。对手涂装、车手名单和标记颜色一致。

## 驾驶学院

三课分别使用大奖赛长环、北环赛道和俱乐部短环的实际路段。每课检测速度、位置及操作条件。原生按键测试在停车区内停稳并保存银牌，加载下一课后确认滚动起步、暂停、重试和成绩保留。模型回归覆盖键盘点按和模拟手柄输入的三课通过路线。

Xbox A 短按和摇杆导航已经使用虚拟 macOS 控制器验证。实体蓝牙震动留待在游戏内测试。 [八车座舱试听](Audio-3.0/Eight-car-audio-tour.wav) · [第三方资源署名](../Assets/THIRD-PARTY-NOTICES.md)

此版通过 1,144 项回归。另使用 AppKit 窗口完整跑过一场比赛，验证自动结算、实际回放、进度跳转、播放速度、视角切换和重赛。回放前后的正式成绩一致。
