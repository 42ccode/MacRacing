# APEX Lab 3.0 Preview 47 进站、座舱回放与声音

## 三种停车服务

原生比赛里依次测试换胎和维修、单独维修、单独换胎。三次服务分别耗时 12、14、12 秒。停车期间比赛、对手和遥测推进。暂停冻结计时和刹车盘冷却。维修保留已装轮胎的磨损、平斑和压力，换胎保留未维修的发动机损伤，两者都保留自然冷却后的刹车盘温度。无损伤时单独维修显示零工作量。

## 座舱回放和车门

回放的驾驶舱使用原机位、设定座高、车内声音和实际后视镜。暂停可以向两侧观察。拖动回放后，从新的赛车位置重新渲染车内镜面。MX-5 的两侧窗导轨移入原始车门铰链，两门复位后截图与开门前逐像素一致。车型署名见 [车辆资源说明](../Assets/Vehicles/README.md)。

原生两圈赛后，三个镜面的纹理在暂停的驾驶舱中全部就绪。左右观察不推进回放时间，拖动后中心镜显示新位置。900 × 664 点窗口中的回放控制全部可达。全量回归通过 1,300 项检查。

## 离线声音与路肩反馈

关闭油门降挡时，驾驶舱的低频随离合器重新传递反拖的时刻进入。在河谷环线用 MX-5、Ferrari 458 和 Porsche 911 对照，湿地刹车的四轮合成甩水声比旧版最强单轮低约 9%–11%。左右互换的输入在湿地输出对应的声道互换，干地和四轮等量甩水保持逐样本一致。

在相同车轮速度和接地点下，上坡产生的持续垂向运动继续作用于悬挂。方向和幅度符合原路肩形状的短促震动单独传到手柄和车内路肩声。六条赛道、两种路况和三辆车共 36 圈物理对照中，圈速与轮载数值逐样本一致。实体手柄可从 F11 校准页检查握把和扳机反馈。
