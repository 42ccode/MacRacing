# APEX Lab 2.0 RC4 验证记录

参考 Dave Kaemmer 对轮胎接地印迹、联合滑移和过峰后抓地变化的公开说明。APEX Lab 采用自己的实验参数，纵向轮胎力通过接地响应逐步建立，制动与转向共享每轮的抓地预算。路面边界使用 22 cm 的过渡区近似胎面覆盖。 [iRacing 轮胎力技术文章](https://www.iracing.com/the-sticking-points-in-modeling-tires/)

450 项自动检查通过，覆盖 ABS、制动力分配、热衰减、双移线、低速制停和新增的纵向接地响应与草地边界。另用 Mazda MX-5 和 Centenario 从 108 km/h 制动入弯，分别保持刹车和逐渐松刹，检查相同转向输入下纵向减速度与侧向加速度的变化。

在 M4 Pro 上，驾驶舱、后视镜和三辆电脑车开启，自动驾驶连续运行 30 秒。将后视镜改为异步回读后，主循环间隔中位数为 8.84 ms，P95 从同步版的 24.29 ms 降到 17.16 ms。平均每秒 104.3 次游戏更新和 120 次 SceneKit 渲染回调。该测试记录游戏读取时机，实体蓝牙手柄的上报间隔和实际手感留待试玩确认。
