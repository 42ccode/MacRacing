## 仿真精度的验收依据

先选 Mazda MX-5 作为道路车基准，再用具备显著下压力的车型验证高速工况。每次调整保留可重复的工况与遥测。车辆实测比较使用相同轮胎、路面、温度、车重和初速。

| 方向 | 当前进展 | 用什么判断接近参考 |
| --- | --- | --- |
| 车辆动力学 | 四轮联合滑移、分轴气动、制动压力和车损 | 匹配直线制停、定圆、带刹入弯、单侧低抓地制动和过路肩的速度、偏航、轮载与制动距离。需要实车或可靠测试数据 |
| 赛道与环境 | 六条原创干湿赛道、高原高程和横坡、浅水线与积水 | 用测绘和实测验证高程、横坡、排水和动态橡胶沉积 |
| 输入与反馈 | 120 Hz 游戏更新目标、Xbox 兼容震动、轮胎擦地声 | 实测输入到画面的延迟、蓝牙丢报和有线方向盘的自回正力矩与稳定性 |
| 车辆与赛道画面 | 授权车模、MX-5 实时原仪表、实时后视镜、固定步长画面插值 | 逐车核对坐姿、车内比例、镜面视野、材质和颠簸动画 |
| 性能与稳定性 | 隐式轮速优化、异步后视镜、12,000 帧离屏 Metal 长跑 | 在目标显示器上测量实际呈现间隔、最慢 1% 和热稳定性 |
| 比赛与训练 | 有效圈、幽灵车、分段遥测、离线短赛、干地直道超车 | 增加更长的比赛、天气与进出站策略，再验证多人同步 |

轮胎、气动和路面参数当前仍是实验预设。正式评估驾驶接近程度需要标定数据与实体设备验证。 [iRacing 车辆技术](https://www.iracing.com/car-technology/) · [iRacing 赛道技术](https://www.iracing.com/track-technology/)
