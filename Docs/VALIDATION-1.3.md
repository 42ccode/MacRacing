# APEX Lab 1.3 验证记录

## 自动检查

`./test.sh` 退出码 0，**135 项通过、0 失败**，覆盖物理、场景、车型、视角与音频，保留 1.2 的全部回归。本版新增 19 项：

- 0 / 1 / 3 / 5 级辅助在草地加速和制动中产生对应的实际限扭 / 卸压；0 级两者均为零。
- TCS 等级升高时，固定条件下的驱动轮累计滑移逐级降低，强 TCS 限扭多于弱 TCS。
- ABS 等级升高时，固定条件下的前轮累计锁止滑移逐级降低。
- 四条赛道分别验证非邻接道路 / 护栏通道间距、起终点连续性与中心线投影，以及按序通过检查点后完整有效圈的记录。

以上是实验模型回归，不是制造商 ABS / TCS 标定，不能据此断言最高等级在所有路面都更快。

## 原生界面与渲染

- 开始界面换到俱乐部短环，进入赛道后以键盘加速，确认车型信息、辅助等级、轮胎 / 悬挂 / G 表和小地图显示正常。
- 开始 / 暂停状态切换到技术公园与大奖赛长环，确认赛道名称、长度、小地图和场景同步切换。
- 暂停界面点击 TCS 从 5 级循环至 0 级，退出并重新启动应用；确认大奖赛长环、ABS 5 / TCS 0 与所选 Porsche 被恢复。
- `Tools/TrackReview.swift` 为四条路线生成原生 Metal 俯视检查图，检查道路、护栏和维修区布局；检查视角将雾距移远，以便从 800 米高处观察路线，不是可选驾驶视角，也未后期修图。

## 兼容性与边界

新增地图沿用现有素材及许可，都是原创平面闭环，使用同一日间干地环境；不是实地扫描赛道。模型和声音的边界见 1.2 验证记录及素材署名。换图 / 换车重置当前最佳圈和幽灵车，未实现各组合独立排行榜。版本 1.3 保留旧辅助设置，但不继承旧最佳圈。

实体 Xbox 输入与震动仍待实测；键盘 / 鼠标原生界面检查不替代实体手柄测试。未做本版目标设备性能基准。应用采用本地临时签名，尚无 Developer ID 公证。
