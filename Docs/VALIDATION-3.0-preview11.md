# APEX Lab 3.0 Preview 11 验证

滚动阻力按每个轮胎的实际轮载、胎压、轮胎损伤、草地覆盖和水深计算。胎压降低时，胎体变形的滚动损耗和温升增加，沥青边缘的阻力随接地比例过渡。

同一台 MX-5 从 108 km/h 空挡滑行 20 秒。1.30 bar 冷压组结束为 81.35 km/h、右前胎 38.96°C。2.10 bar 组结束为 82.93 km/h、右前胎 37.07°C。默认冷压高低仍有抓地和热状态的取舍。

湿地水雾仍从实际轮胎位置生成。远处车辆逐步减少粒子，频繁的小幅强度变化合并更新。559 项自动检查、35 项原生练习和 81 项原生界面检查通过。

胎温、压力与滚动损耗的方向参考官方车辆调校资料。具体数值使用 APEX Lab 自有的实验参数。[iRacing Gen 3 Supercars 手册](https://s100.iracing.com/wp-content/uploads/2025/06/Gen-3-Supercars-Manual_V5.pdf)
