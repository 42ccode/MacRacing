# APEX Lab 2.0 RC24 验证记录

520 项自动检查与 31 项隔离原生应用检查通过。发布包通过签名、ZIP 完整性和 65 个资产 SHA-256 检查。包内没有本地练习、遥测或存档数据。

离线短赛为倒计时和绿灯使用不同提示音。离线音频检查覆盖双声道居中、不同长度、一次性播放，以及静音与暂停后的安静状态。

本轮累计验证包括六图干地短赛、北环湿地短赛、三档制动与转向、分区胎温、高原高差、尾流及护栏擦碰。历次测试与量化对照见 RC6–RC23 验证记录。

最终版本在 Apple M4 Pro 以 1440×900 运行高原环座舱，渲染玩家与三辆对手车，每八帧渲染一次后视镜。干湿各 12,000 个离屏 Metal 命令全部完成。
