# APEX Lab 1.4 — Mac 驾驶模拟原型

解压后，双击 **APEX Lab.app**。支持 Apple Silicon Mac，macOS 14 或以上；不需要安装 Unity。

应用旁会创建 `APEX Lab Data` 保存练习设置、最佳圈和遥测，请将应用保留在可写文件夹中。

## 本版修复

修正 Porsche 前轮歪轴滚动及卡钳跟随轮圈旋转。前轮现在按内外轮不同转角运动；轮胎横向力逐步建立，车型横摆惯量按质量与尺寸估算。连续左右转向、回正和静止时 TCS 读数均增加回归检查。

物理参数仍为实验预设，未经实车标定；本版保留操作设置，但重置旧最佳圈与幽灵车。

## 开始驾驶

开始界面的箭头可预览 **六种视角**，并在 Concept GT、Ferrari 458、Porsche 911 Carrera 4S 之间选择。先在 macOS 中连接 Xbox 手柄，再进入赛道。没有手柄时可以直接使用键盘。

| 操作 | Xbox | 键盘 |
| --- | --- | --- |
| 开始 / 确认 | A / Menu | 回车 |
| 转向 | 左摇杆 | A / D 或左右方向键 |
| 油门 / 刹车 | RT / LT | W / S 或上下方向键 |
| 升挡 / 降挡 | B / X，或 RB / LB | E / Q |
| 循环六种视角 | Y | Tab |
| 开始 / 暂停界面换车 | 十字键 ← / → | C 或界面箭头 |
| 开始 / 暂停界面换赛道 | 十字键 ↑ | N 或赛道按钮 |
| 循环 ABS / TCS 等级 | 界面按钮 | 1 / 2 |
| 车外左右环视（松开回中） | 右摇杆 | 按住 J / L |
| 调整车内视场角 / 座高 | — | [ / ]、Page Up / Page Down |
| 显示或隐藏 HUD / 保存驾驶画面 | — | V / F12 |
| 复位到赛道（保留车损） | 长按 A | R |
| 拖回维修区 · 12 秒修车换胎 | 十字键 ↓ | P |
| 暂停 / 继续 | Menu | Esc |

车内与车外视角的转向方向一致。引擎声音使用实录底音，进入驾驶后即可听到怠速，M 切换静音。

左侧与暂停菜单可点击 ABS / TCS 按钮，或按 1 / 2，循环调整 0–5 级；0 关闭、5 强介入，默认 3 级。等级改变制动卸压 / 限扭，不代表等级越高圈速越快。暂停界面还可调自动挡、声音、摇杆死区和幽灵车。驶出赛道缓冲区会使本圈无效；复位后按提示回到起点计时。

本版包括四条原创赛道、精细车辆及座舱、四轮独立接地力、车身升沉/俯仰/侧倾、胎面/胎体温度、热态胎压、磨损、平斑、爆胎及碰撞车损、圈速、幽灵车和遥测。仅有前进挡，未实现倒挡/空挡/离合。

当前为尚未实车标定的原型。Xbox 实体手柄输入和震动需实测，60 FPS 为目标而非已测结果。

## 赛道与新增信息

开始或暂停界面点击赛道按钮，或按 N / Xbox 十字键 ↑ 循环选择：北环赛道 1.45 km、俱乐部短环 1.23 km、技术公园 1.59 km、大奖赛长环 2.29 km。四条赛道共用日间干地环境，布局分别偏向均衡、中速连续弯、紧凑变向和高速长直道。

换图会重开练习，并清除当前最佳圈和幽灵车；车辆、视角及辅助等级保留。赛道与等级在退出后自动保存。1.4 沿用旧设置，但重置旧版最佳圈；尚不提供按车辆 / 地图组合存储的独立排行榜。

左侧面板显示车型、实验质量、驱动形式、水温、可用动力、前后车身 / 引擎 / 悬架损伤、滑移与复位后的里程。损伤 0% 表示完好，悬架数值取四角最大损伤；可用动力为损伤与散热影响后的动力系数，不是实时马力。ABS 卸压 / TCS 限扭显示本物理步最大介入百分比。下方小地图白方块是起点，圆点及短线是车辆位置与朝向。

## 轮胎、车损和维修

右侧四轮图示按驾驶员左右排列，查看温度、压力、剩余胎面、接地路面和爆胎状态；底部显示最大部件损伤和水温。冷胎、过热、胎压偏离、磨耗和爆胎都会改变抓地力；悬架碰撞损伤会造成跑偏，车头损伤会影响散热和动力。

暂停菜单选择软 / 中 / 硬胎、调整冷胎压，下一次维修或重新开始时生效。冷胎压基准为 26°C，新胎为 38°C，仪表显示的当前压力会略高于冷压设置。软胎抓地较高但磨损较快。

按 P / 十字键 ↓ 将车拖回发车区，12 秒后完成修复和换胎；暂停会暂停倒计时。R 仅复位，保留损伤和轮胎状态。“重新开始”才会直接开启完好车辆的新练习。1.0 不继承旧物理版本的最佳圈，保留原辅助和视角设置。

车身前后部有简化变形，尾翼和轮胎外观随损伤变化；目前没有零件脱落、玻璃破碎或软体碰撞求解。

## 车辆与视角

Y / Tab 依次切换驾驶舱、仪表台、引擎盖、保险杠、近距跟车和远距跟车。仪表台视角隐藏方向盘，跟车视角可以环视。暂停或开始界面使用十字键左右、C 或界面箭头换车；换车会重开练习并清除当前最佳圈和幽灵车，车辆选择自动保存。

Ferrari 458 模型带原作者提供的详细座舱；Porsche 911 Carrera 4S 原资源偏重车外，当前使用新增的简化座舱。三款车采用不同实验质量、轮距、轴距、轮径和扭矩，均使用项目的后驱六速动力传动和共享引擎声音，不等同于相应实车，4S 外观也未模拟四驱。

## 悬挂、G 值和路肩

四根弹簧随实际悬挂状态变化，正值表示相对静态车高压缩、负值表示伸张，单位 mm；下方为当前轮载 kN。加速时后悬挂压缩，制动时前悬挂压缩，转弯时两侧随载荷转移变化。

G 表外圈为 2 G，横向向右为正、纵向加速为正，轨迹保留约 1.5 秒。超出外圈时数值继续显示，光点限制在圆周。

压上路肩的轮胎和悬挂变为橙色，并显示反馈强度；颠簸声和兼容手柄的震动随车速及接触激励变化。停在路肩上不会持续震动。按 V 可以隐藏整个仪表。
