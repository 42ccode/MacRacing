# APEX Lab 3.0 Preview 33 湿地材质与护栏

湿地使用 Greg Zaal 拍摄的 CC0 阴天天空，全局雾和直射光也随天气变化。道路从轮胎正在使用的同一水膜函数采样。水深改变路面底色、粗糙度、上层水膜和低视角的天空反光。停车实机渲染对比了河谷环线四段坡形的干湿画面。 [Poly Haven 阴天天空](https://polyhaven.com/a/kloofendal_overcast_puresky) · [视频与材质署名](../Assets/THIRD-PARTY-NOTICES.md)

可见护栏与碰撞使用相同的内侧边距。轮廓按车身长宽与前后悬估算，碰撞在车身接触点计算法向冲量和切向摩擦。玩家和 AI 使用同一检查。测试以模拟 331 km/h 朝两侧护栏分别撞击八辆车，车身前缘接触后每辆车都留在栏内。擦碰、正碰与离开护栏时的速度响应另有验证。
