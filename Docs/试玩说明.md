# APEX Lab 1.13 — Mac 驾驶模拟原型

解压后，双击 **APEX Lab.app**。支持 Apple Silicon Mac，macOS 14 或以上；不需要安装 Unity。

应用旁会创建 `APEX Lab Data` 保存练习设置、最佳圈和遥测，请将应用保留在可写文件夹中。

## 本版变化

新增 SDC PERFORMANCE 的 Lamborghini Centenario。车身、门板、座椅、方向盘和仪表都来自同一完整授权模型。新安装默认选中，已有配置可在开始或暂停菜单用 C 或 Xbox 十字键左右换车。HUD 提供实时速度、挡位和踏板读数。

更新了赛道铺装、磨耗标线、胎痕、起终点棋盘格和维修楼细节。按 F7 可在完整与精简 HUD 间切换，精简模式保留后视镜、小地图、圈时、分段与踏板条。F6 仍可移动全部仪表。仪表模式和位置会自动保存。

驾驶舱和仪表台视角默认开启虚拟后视镜，镜框哪一侧亮黄灯，就表示该侧有电脑车接近。按 B 或点击暂停菜单「后视镜」切换。Xbox 右摇杆向左或向右推可以转头观察，键盘用 J / L。松手后视线回正。

六张赛道均有可驾驶维修道。在起终点前从行车方向右侧的 PIT IN 进入，沿蓝色边线开到 BOX 黄框。白线之间限速 60 km/h。限速器默认开启，可按 K 或点击输入条上方的开关切换，设置会保存。

在黄框内停稳后，按 P 或 Xbox 十字键 ↓ 开始 12 秒修车换胎。暂停会冻结倒计时。车辆无法自行进站时，按 Shift+P 或使用暂停菜单「拖车维修」。完成后按 E 或 Xbox B / RB 挂入 1 挡，从 PIT OUT 并回主赛道。出场圈不参与个人最佳，下一次正向越过主赛道起终点后开始计时。

倒车时先接近静止，松开油门并踩住刹车。按 Q 或 Xbox X / LB 进入 N，等挡位显示 N 后再按一次进入 R。松开刹车用油门倒车。停车后踩住刹车，按 E 或 B / RB 依次回 N 和 1。

车况面板新增前轴制动力分配。键盘 4 / 5、驾驶中的 Xbox 十字键左右、面板减号 / 加号均可调整。每次 0.5 个百分点，各车型独立保存。

进入赛道后按 F6，或点击暂停菜单「布局编辑」。鼠标可拖动九个描边面板，包括虚拟后视镜。点击「保存布局」或再按 F6 完成，可用「恢复默认」重新摆放。编辑时练习暂停，窗口大小变化后面板仍保持在屏幕内。

新增 BMW M3 E30、Mazda MX-5、高原高速环（2.40 km）和河谷环线（1.82 km）。在开始或暂停菜单按 C 换车、N 换赛道，Xbox 可用十字键切换。

开始或暂停菜单用 O 或「电脑对手」选择 0–3 辆。蓝、橙、绿色车辆会用不同节奏沿赛道行驶，前方有车时减速。小地图上的同色点表示电脑车位置。车辆接触会产生碰撞响应，较重接触会计入玩家车损及兼容手柄反馈。

按 U、Xbox 右摇杆按下或菜单「自动驾驶」可切换。自动驾驶接管油门、刹车、转向和换挡，操作踏板或转向即可接回。开启前请让车辆面向赛道方向。自动驾驶圈不计入个人最佳，对手数量会保存，自动驾驶在每次启动时关闭。

理想线路默认开启。绿色提示加速，黄色提示收油，红色提示制动。按 I、Xbox 左摇杆按下，或使用暂停菜单「理想线路」切换。左下角速度采用赛道曲率和统一干地参数估算，可作为练习参考。

1.6 顶部新增圈速差和三段计时。先完成一个有效圈建立参考；之后负值表示在同一赛道位置比个人最佳更快，正值表示更慢。S1 / S2 是小地图中的分段点，S3 在终点完成。面板标明本圈 / 上圈分段；无效圈、出场圈和没有参考时不显示差值。

换车或换图会保存原组合、恢复目标组合的最佳圈及幽灵车，退出后仍保留。六车六图共 36 组个人记录；辅助和轮胎方案暂不另外区分。出界、持续逆行、跳过检查点会令本圈无效，不能刷新最佳。复位到起点以外需先通过起点。首次从 1.5.x 升级会保留偏好并清除一次旧圈时。

输入横条增加八段转速提示，随转速从绿色到黄色、红色点亮，帮助手动换挡。

1.5.2 左下角改为截图风格的横向驾驶输入条。从左到右是最近 5 秒的输入曲线、LT 刹车 / RT 油门实时柱、挡位、车速和动态方向盘。绿线为油门，红线为刹车，ABS 介入时刹车段显示黄色。曲线从右向左滚动，暂停或维修时冻结，复位 / 换车 / 换图 / 重开时清空。方向盘指示左摇杆 / 键盘转向输入，不代表方向盘力反馈。按 V 隐藏 / 显示。

新增防倾杆、悬挂缓冲、刹车热衰减；左侧车况面板显示刹车温度与可用制动力。路肩采用与物理共用的立体轮廓，赛道增加看台、标柱和维修物件，Porsche 座舱增加动态指针仪表。

Xbox One 蓝牙连接后，开始驾驶并按 Menu / Esc 暂停，点击「测试手柄震动」。测试依次播放左、右、刹车、油门四段短脉冲；缺少扳机能力时折算到对应手柄马达。菜单显示 macOS 实际开放的反馈能力，强度可按 0 / 25 / 50 / 75 / 100% 循环调整，默认 75%。若显示不可用，驾驶输入仍可使用，程序不会假报震动已经生效。

行驶时压路肩、草地、打滑、ABS 与碰撞会触发不同反馈。暂停、失焦、断连及维修停止行驶反馈；暂停菜单的测试为手动短时例外。物理参数未经实车标定，本版保留设置并重置旧最佳圈和幽灵车。

## 开始驾驶

开始界面的箭头可预览 **六种视角**，并在 Concept GT、Ferrari 458、Porsche 911 Carrera 4S 之间选择。先在 macOS 中连接 Xbox 手柄，再进入赛道。没有手柄时可以直接使用键盘。

| 转向 | 左摇杆 | A / D 或左右方向键 |

车内与车外视角的转向方向一致。引擎声音使用实录底音，进入驾驶后即可听到怠速，M 切换静音。

左侧与暂停菜单可点击 ABS / TCS 按钮，或按 1 / 2，循环调整 0–5 级；0 关闭、5 强介入，默认 3 级。等级改变制动卸压 / 限扭，不代表等级越高圈速越快。暂停界面还可调自动挡、声音、摇杆死区和幽灵车。驶出赛道缓冲区会使本圈无效；复位后按提示回到起点计时。

本版包括六条原创赛道、精细车辆及座舱、四轮独立接地力、车身升沉/俯仰/侧倾、胎面/胎体温度、热态胎压、磨损、平斑、爆胎及碰撞车损、圈速、幽灵车和遥测。变速箱提供 R、N 和六个前进挡。

当前为尚未实车标定的原型。Xbox 实体手柄输入和震动需实测，60 FPS 为目标而非已测结果。

## 赛道与新增信息

开始或暂停界面点击赛道按钮，或按 N / Xbox 十字键 ↑ 循环选择：北环赛道 1.45 km、俱乐部短环 1.23 km、技术公园 1.59 km、大奖赛长环 2.29 km、高原高速环 2.40 km、河谷环线 1.82 km。六条赛道使用日间干地环境。

换图会重开练习，保存原组合记录并恢复目标组合的最佳圈和幽灵车；车辆、视角及辅助等级保留。赛道与等级在退出后自动保存。1.6 保留操作设置，清除一次旧版圈时，之后按车辆 / 地图组合保存独立个人最佳。

左侧面板显示车型、实验质量、驱动形式、水温、可用动力、前后车身 / 引擎 / 悬架损伤、滑移与复位后的里程。损伤 0% 表示完好，悬架数值取四角最大损伤；可用动力为损伤与散热影响后的动力系数，不是实时马力。ABS 卸压 / TCS 限扭显示本物理步最大介入百分比。下方小地图白方块是起点，圆点及短线是车辆位置与朝向。

## 轮胎、车损和维修

右侧四轮图示按驾驶员左右排列，查看温度、压力、剩余胎面、接地路面和爆胎状态；底部显示最大部件损伤和水温。冷胎、过热、胎压偏离、磨耗和爆胎都会改变抓地力；悬架碰撞损伤会造成跑偏，车头损伤会影响散热和动力。

暂停菜单选择软 / 中 / 硬胎、调整冷胎压，下一次维修或重新开始时生效。冷胎压基准为 26°C，新胎为 38°C，仪表显示的当前压力会略高于冷压设置。软胎抓地较高但磨损较快。

进站与维修保留此前的个人最佳。R 复位保留损伤和轮胎状态。选择「重新开始」可用完好车辆开启新练习。

车身前后部有简化变形，尾翼和轮胎外观随损伤变化；目前没有零件脱落、玻璃破碎或软体碰撞求解。

## 车辆与视角

Y / Tab 依次切换驾驶舱、仪表台、引擎盖、保险杠、近距跟车和远距跟车。仪表台视角隐藏方向盘，跟车视角可以环视。暂停或开始界面使用十字键左右、C 或界面箭头换车；换车会重开练习、保存原组合并恢复目标组合的最佳圈和幽灵车，车辆选择自动保存。

Ferrari 458 模型带原作者提供的详细座舱；Porsche 911 Carrera 4S 原资源偏重车外，当前使用新增的简化座舱。六款车采用不同实验质量、轮距、轴距、轮径和扭矩，均使用项目的后驱六速动力传动和共享引擎声音，不等同于相应实车，4S 外观也未模拟四驱。

## 悬挂、G 值和路肩

四根弹簧随实际悬挂状态变化，正值表示相对静态车高压缩、负值表示伸张，单位 mm；下方为当前轮载 kN。加速时后悬挂压缩，制动时前悬挂压缩，转弯时两侧随载荷转移变化。

G 表外圈为 2 G，横向向右为正、纵向加速为正，轨迹保留约 1.5 秒。超出外圈时数值继续显示，光点限制在圆周。

压上路肩的轮胎和悬挂变为橙色，并显示反馈强度；颠簸声和兼容手柄的震动随车速及接触激励变化。停在路肩上不会持续震动。按 V 可以隐藏整个仪表。
