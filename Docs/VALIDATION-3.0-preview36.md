# APEX Lab 3.0 Preview 36 四轮制动

八辆车各有一组前后轮旋转惯量，单位是 kg·m²。参数来自制动、轮胎和车轮尺寸的模拟标定。低载荷测试分别对前后轴施加已知制动扭矩，验证轮速变化与对应的惯量一致。

游戏的固定物理步长为 1/240 秒。每步三个轮胎与悬架子步。ABS 每秒更新 120 次各车轮的压力目标，卸压快于回压，估计的阀门流量驱动制动扳机、兼容握把和座舱声。湿地重刹时单轮首先达到滑移限值，稳压阶段的反馈随之减弱。制动管路回落后，阀门活动和制动震动归零。

六条赛道在干地和湿地分别运行四车两圈短赛。验证起步、完整完赛、硬碰撞、越界处罚及完赛减速。原生场景验证八辆车的驾驶位与镜面。方向盘与踏板手感仍需玩家实驾评价，实体 Xbox 蓝牙震动留待游戏内确认。

可试听 [八车座舱音频](Audio-3.0/Eight-car-audio-tour.wav) 和 [MX-5 负载过渡](Audio-3.0/MX5-load-transitions.wav)。录音车型和素材许可证见 [第三方资源署名](../Assets/THIRD-PARTY-NOTICES.md)。
