# APEX Lab 3.0 Preview 53 验证记录

## 车身接触位置

三圆碰撞轮廓分别使用各车原模型的半车宽、前伸和后伸尺寸。八款车两两组合的 192 个侧向、尾追和迎面边界均与模型尺寸对齐。此前的通用尺寸在 171 个组合中相差超过 5 厘米。4,992 组斜向投影中，简化碰撞轮廓与车身顶点投影的平均绝对偏差从 19.1 厘米降至 13.6 厘米。最不利斜角仍相差约 66 厘米。

八车、六条赛道、干湿地、前后两种发车配置合计 192 场四车对照，两套几何各有 768 车次完赛，排序、计时和罚时逐项一致。另测 80 组主动制造接触的车流、重返赛道、停车和出站合流场景。危险重返赛道时，对手重接触事件由 55 次变为 56 次，最高法向相对速度由 18.17 m/s 升到 19.13 m/s。

## 车轮与遥测

八款车的对手模型均验证了爆胎后的可见半径和悬架损伤倾角，以及维修后的复原。回放复用同一套车轮显示逻辑。

以 10 Hz 采集 114 列遥测时，CSV 文本转换在后台串行完成。干地采样调用的主线程耗时中位数从 0.0826 ms 降至 0.0072 ms，湿地从 0.0699 ms 降至 0.0087 ms。这项测量针对采样调用本身。相同确定性输入下，36,000 行 CSV 的 28,790,521 字节输出完全一致，并验证了暂停、恢复驾驶、保存失败后的重试和退出前写入。

## 静音验收

1,289 项非手柄回归检查通过，另行验证普通练习保存、菜单导航、自动驾驶完赛及离线回放。驾驶与声音测试全程静音。实体蓝牙手柄效果留待玩家试驾。
