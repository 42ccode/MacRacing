# APEX Lab 3.0 Preview 57 验证记录

## 松刹与转向

前轮接地橡胶在滑动时会更快释放纵向变形。按相同踏板和转向，在北环以 240 Hz 采样急松刹并换向的一段。以前轴力相邻增量之差的均方根衡量短时力跳动，数值越低，连续两个物理步之间的变化越平顺。

| 车型 | 干地，改前 → 改后 | 湿地，改前 → 改后 |
| --- | --- | --- |
| Porsche 911 Carrera 4S | 104.5 → 77.1 N | 57.1 → 45.3 N |
| Lamborghini Centenario | 82.6 → 67.8 N | 107.2 → 77.2 N |

两车 0–100 km/h 的仿真时间变化最多 0.1 毫秒，100–0 km/h 距离变化最多 0.071 米。另做了 72 组不同制动曲线、ABS 设置和路面抓地组合的松刹检查，液压回落时序一致。

## 在 F8 里检查一个弯

每条新有效圈保留 801 个等距离位置，逐点记录原始控制、实测管路压力、方向盘角度和车速。可在光标处放大 10 倍。201 个位置的旧圈按距离对齐，缺失的角度显示为「—」。在 1200 米测试闭环中，旧采样点之间一个 5.6 米宽的制动动作未留下踏板峰值；新记录采得 85.0% 踏板、46.5% 液压和向右 38.2° 的方向盘角度。

## 湿地爆胎进站

电脑车在湿地前轮爆胎时，进站分流前提前降速。两辆车在六条赛道的 120 个左右前轮爆胎案例中完成 120 次进站服务，改前为 115 次。相同场景下较重的玩家接触从 15 次降到 6 次。健康车、干地案例和湿地后轮爆胎对照保持原表现。全部为离线游戏物理实验。

北环 576 米处，分别用两种速度策略让每款车实际跑完计时圈，再用原生练习分析读取。较慢的 911 松刹时，踏板 32.5%、管路压力 10.0%、方向盘左转 82.1°；同位置 Centenario 为 34.0%、11.0%、左转 74.5°。截图为游戏物理回归产生的驾驶轨迹。 [911 弯段](Driving-3.0/preview57-porsche-braking.jpg) · [Centenario 弯段](Driving-3.0/preview57-centenario-braking.jpg)

## 驾驶位左镜

将垂直视野调为 42°，在 900 × 664 窗口测试三种座高。满幅向左看时，911 左镜最差可见面积由 65.16% 提升至 97.92%，Centenario 由 0 提升至 99.95%。52° 时 Centenario 的最差结果由 39.06% 提升至 99.95%。右侧和正常 62° 视野沿用原视角。 [左右对照及后车影像](Driving-3.0/preview57-narrow-mirrors.jpg)
