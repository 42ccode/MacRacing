# APEX Lab 0.4

43 项自动检查通过，覆盖车辆动力学、计时、模型与视角、转向方向和音频输出。原生应用已通过启动、进入赛道、键盘加速与左右转向、车内外切换、复位和制动的操作检查。

相机方向回归检查从相同位置起步，用正负两种输入驱动车辆，在车内和后方跟车两种视角分别检查车辆相对屏幕右轴的位移、前轮转向和方向盘转动。左右位移分别为 −1.57 米和 +1.57 米。

12 秒试听由与游戏相同的 AVAudioEngine 和实际车辆动力学离线渲染。录音从怠速开始，加速经过一、二、三挡，再松油和制动。怠速 RMS 0.101，给油 RMS 0.175，输出峰值 0.450，静音和暂停后输出降到零。试听录音和游戏素材署名在应用资源文件 THIRD-PARTY-NOTICES.md 中。

实体 Xbox 手柄和用户 Mac 的扬声器仍需实机确认。
