# APEX Lab 1.0 验证记录

## 自动检查

`./test.sh` 覆盖车辆动力学、圈速、轮胎状态、机械损伤、模型与视角以及 AVAudioEngine 输出。最终结果共 62 项通过。

- 相同滑移功下，软胎比硬胎磨耗更快；胎面升温传至胎体，带动胎压升高，停车后冷却。
- 旧胎在完整车辆求解器中具有更长刹停距离。持续抱死会累积平斑，达到极限后磨穿泄压；损伤单侧轮胎和悬架后，车辆保持数值稳定并产生跑偏。
- 前、后、侧向碰撞分别更新对应部件，低速轻触不产生损伤。复位保留状态，维修恢复机械状态及所选轮胎方案。
- 连续十分钟模拟带损伤的加速、转向和周期制动，检查速度、位置、轮温、胎压、磨耗和载荷有限且有界。这是模拟时长，不能代替目标设备上的长时间性能测试。
- 怠速恒温检查通过；正常引擎水温维持在工作温度附近。
- 车内外左右转向、方向盘与前轮方向一致。碰撞会修改外部车身几何、尾翼及轮胎姿态；维修恢复原始几何。
- 同一游戏音频链路离线检查怠速、加速、升挡断火、静音与暂停。音频无非有限值或削波，输出峰值约 0.45。

## 原生应用操作检查

通过正常入口启动 1.0，检查暂停菜单无裁切，切换硬胎并把冷压从 1.65 调到 1.70 bar。完成 12 秒服务后，状态面板显示硬胎与约 1.81 bar 的热态压力。

键盘实际驾驶撞护栏后，面板记录车头约 22%、悬架约 14%、引擎约 11% 损伤。按 R 复位后这些损伤保留；按 P 完成维修后损伤归零，胎面余量恢复 100%。车内外切换正常。

## 范围

这是原型 1.0 的功能版本。轮胎参数、热与磨损模型、碰撞损伤阈值均为实验参数，尚未实车标定。车损外观为有界变形，保留原拓扑及材质；没有软体碰撞、零件脱落或玻璃破碎。没有联网、AI 对手和雨地模型。

实体 Xbox 手柄与震动尚未实测；60 FPS 为目标值。发布包使用本地临时签名，尚未做 Developer ID 公证。
