# APEX Lab 3.0 Preview 32 制动盘热模型与轮胎耗散

制动热输入来自每轮的液压摩擦扭矩和实际轮速。热量先进入摩擦面，再导入盘体，并按速度与水膜改变对流散热。车型的盘体容量、散热与热衰减参数是工程估算，参考公开材料与赛车刹车温度资料。 [制动盘热特性实验](https://eprints.whiterose.ac.uk/83732/1/Abdulwahab%20Thermal%20Eng.pdf) · [AP Racing 温度资料](https://catalogue.apracing.com/46/)

MX-5 从 122.4 km/h 施加 1.2 秒 90% 踏板后，前盘面约 136.8°C、盘体约 43.0°C。随后以复位保留热状态，在静止三秒后测得盘面约 99.7°C、盘体约 53.0°C。在 Honda e 上，同样从 90 km/h 刹车 0.65 秒，D 挡回收时后盘面约 64.7°C，空挡纯液压约 72.9°C。

胎面使用滑动区的摩擦功与黏着区估计的少量滞后损失。胎体滚动弯曲、压力和冷却继续单独计算。轮胎接地测试覆盖纵向锁止、横向擦滑、含水路面和路肩。

路面数据在三个轮胎子步之间复用。在加入热模型前，八车混合干湿、坡路和边缘的 288,000 步对比给出相同的轨迹与接地量二进制校验。车轮求解频率仍为 720 Hz。
