# APEX Lab 3.0 Preview 21 驾驶物理验证

使用模拟器的 Mazda MX-5 预设，对 Git 标签 `v3.0.0-preview20` 和 Preview 21 分别运行相同输入。三个工况均为空挡、平路、零油门。入弯和直线制动按 240 Hz 输入，车轮每秒计算 720 步。当前工况保存在 `Tests/PhysicsChecks.swift` 的 `checkCombinedSlip()` 和 `wetStop(depth:compound:)`，运行 `./test.sh` 可复核。

## 抱死前轮的摩擦力方向

车轮完全抱死时，接地点以车轮中心的地面速度滑动。将前轮接触力转回车身坐标，测量其与地面速度反方向的夹角，理论值为 0°。测试关闭 ABS，先在静止时踩满制动，再设定纵向速度 24 m/s、横向速度 4 m/s、实际转角 −0.18 rad，向右打满并推进一个 1/720 秒子步。测量右前轮，同时确认轮速仍为零。

| 初始胎面状态 | Preview 20 | Preview 21 |
| --- | ---: | ---: |
| 初始横向变形为零，突然转向 | 19.18° | < 0.000001° |
| 初始横向变形已与各轮侧偏角匹配 | 5.17° | < 0.000001° |

Preview 21 按胎面变形计算黏着区剪切力，按实际接地点滑动速度决定滑动区的摩擦力方向。轮胎完全抱死时，转动方向盘仍会改变轮胎坐标下测到的力分量，但换算回车身坐标后，摩擦力始终指向地面滑动的反方向。接触斑采用抛物线压力分布的刷子模型近似。模型依据见 [Chalmers 的轮胎刷子模型推导](https://research.chalmers.se/publication/548872/file/548872_Fulltext.pdf) 和 [Lund 大学的组合滑移研究](https://www.lunduniversity.lu.se/publication/b68e445a-57d5-419c-946e-c129fec53ec4)。

## 重刹入弯后逐步松刹

起始速度 100.8 km/h，干地、中性胎、初始胎面温度 57°C，关闭 ABS 和 TCS。保持 62% 向右转向输入，同时踩下 90% 制动 350 ms。复制这一时刻的完整车辆状态，分别把制动保持在 90%、松至 45%、完全松开。再经过 200 ms，读取两前轮在各自车轮坐标下的侧向力之和的绝对值。

| 剩余制动行程 | Preview 20 | Preview 21 |
| --- | ---: | ---: |
| 90% | 534 N | 793 N |
| 45% | 1,382 N | 1,779 N |
| 0% | 5,287 N | 6,002 N |

松刹越多，滚动前轮可建立的侧向力越大。即使完全抱死，前轮本身有转角，摩擦力在车轮坐标中仍有侧向分量。单凭表中数值无法判断整车转向能力，回归测试另行检查松刹后的前轮滑移率和车身偏航速度。

## 直线全力制动

起始速度 108 km/h，初始胎面温度 57°C，保持 100% 制动，ABS 为默认 3 档。记录从送入制动指令至车速首次低于 0.2 m/s 的距离，包含制动管路建压时间。湿地四轮的水膜厚度固定为 0.55 mm。

| 路面与轮胎 | Preview 20 | Preview 21 |
| --- | ---: | ---: |
| 干地，中性胎 | 46.9 m | 45.8 m |
| 湿地，中性胎 | 73.8 m | 73.5 m |
| 湿地，雨胎 | 55.5 m | 54.5 m |

这些数据可用于追踪版本间的物理变化。制动距离和入弯侧向力也受到制动平衡、车身载荷转移与轮胎参数影响。本轮尚无同车、同胎、同路面的实车或 iRacing 遥测对照，因此无法量化与两者之间的误差。

## 车身与手柄反馈

Ferrari 458 按前 42%、后 58% 分配静态轮载，Porsche 911 Carrera 4S 按前 38%、后 62% 分配。车身围绕质心转动，轮胎和碰撞使用相对质心的力臂。Honda e 使用 0.50 m 质心高度。其它车型的质心高度和各车型的转动惯量仍使用几何估算。资料见 [458 Spider 原厂手册](https://autocatalogarchive.com/wp-content/uploads/2016/05/Ferrari-458-Spider-2011.pdf)、[MotorTrend 的 992 Carrera 4S 测试](https://www.motortrend.com/reviews/2020-porsche-911-carrera-4s-first-test) 和 [Honda e 技术资料](https://hondanews.eu/eu/el/cars/media/pressreleases/185161/honda-e-the-perfect-balance-of-efficiency-and-performance-for-urban-commuting)。

前轴持续擦滑时使用连续反馈，后轴侧滑时加入脉动。在 79.2 km/h 的测试工况下，后轴扰动使反馈在 100 ms 内出现，直行对照输出为零。测试覆盖连续输出与兼容档位映射。蓝牙 Xbox 手柄的实际强度和延迟仍待游戏内体验确认。

原生练习和短赛遥测均实测导出 110 列；既有 102 列顺序一致，末尾新增四轮滑动比例和侧向力（N）。38 项原生练习与菜单检查全部通过。
