# APEX Lab 3.0 Preview 50 对手进站、内饰与湿地录音

## 对手进站

使用真实车辆求解和维修道几何，对六条赛道注入单胎损伤或仍可行驶的机械故障，验证车辆制动、进站、停稳、服务和出站。八组可维修场景均完成服务，零重接触、零罚时。对照包括两辆同时需要服务、玩家占用维修位、维修位受碰撞推移、正常车流通过合流口，以及终点阶段提前结束服务。榜单按阶段显示对手进站、服务剩余和出站。

## 原内饰材质

Porsche 911 4S 的原仪表台贴图保留，减少表面的金属反光。Lotus Elise 的座椅、门内板与方向盘握持面呈深炭黑哑光。赛道和展厅使用同一套材质。32 张原生对照覆盖赛道驾驶位、展厅左右开门和车外，关门外观每通道平均亮度差低于 0.002/255。

## 实录湿路

水声加入一段经过湿沥青的路边录音，混入现有的四轮甩水计算。用相同的 240 Hz 车辆轨迹和原生离线音频分别渲染 MX-5、Ferrari 458 和 Porsche 911。三辆车的干地输出逐样本一致，湿地水声 RMS 幅度变化约 0.8%–1.2%，峰值相当。差异集中在水声纹理。 [录音原作者与授权](../Assets/THIRD-PARTY-NOTICES.md)

## 完整回归

1,329 项全量检查及 104 项额外原生菜单、画面和进站检查通过。使用同一 Metal 截图和场景加载方案的 Preview 47 完成 32 分钟压力测试，共 224 次车辆、赛道和模式切换。预热后进程占用约 2.3–3.3 GiB，比赛历史按原有 24 场上限轮换，重新启动后可读。
