# APEX Lab 3.0 Preview 29 起步与反拖

五款首次采用车型特定齿比的燃油车接入起步离合。停车时踩住制动并给油，离合打开，曲轴可以先起转，轮端不输出驱动扭矩。松刹后离合开始带载。变速器输入轴转速升高后，切入正常耦合，转速随齿比和驱动轮变化。起步目标转速与离合斜率为模拟参数。

自动挡在升挡前同时检查发动机转速和车身速度。关闭牵引力控制时，458 在低速空转仍可触及限转，但保持一挡，直至车身速度达到足够水平。手动换挡请求继续由驾驶者控制。

收油后，已接合的变速器把车轮动能传回发动机。发动机阻力按车型和转速变化，低速开离合或切空挡后，反拖消失。轮端传回的功率也驱动座舱的反拖音色。

平直干地静止起步，默认辅助、全油门，458 的 0–100 km/h 仍为 5.12 秒，911 为 3.60 秒，E30 为 6.70 秒，Centenario 为 3.40 秒，Elise 为 7.35 秒。在这一条件下，458 的起步受到现有轮胎和牵引力控制标定限制。MX-5 的参考加速仍为 7.20 秒，Honda e 为 8.06 秒。
