# APEX Lab 3.0 Preview 19 验证

- Mazda MX-5 NA 用 Lexyc16 的原作者车身与内饰，BMW M3 E30 用 Artem P 的原作者车身与内饰。两款均采用 CC BY 4.0，保留独立滚动轮和源模型方向盘。Porsche 4S 继续用原作者外观，引擎盖、保险杠和跟车视角可用。其它车型使用各自模型中的仪表外观，实时速度与转速在 HUD 中读出。
- 六车在 1280×720 下渲染外观和驾驶视角，检查车轮轴位、主要驾驶视线、左右镜方向、镜面材质隔离和换车。Mazda 和 Ferrari 的中央镜在源网格上显示后方画面。
- 用 Mazda 在高原干地均衡档连续跑 32 秒，原生 Metal 回调确认中央、左、右三块车身镜面都收到实时画面。Centenario 在北环干地均衡档连续跑 22 秒，左右两块镜面都更新。两段物理更新均为 240.0 步/秒，绘制回调的帧间隔 p95 分别为 10.1 和 11.3 ms。数据来自本机短测。
- 594 项自动检查、36 项原生功能检查、81 项原生菜单检查通过。
