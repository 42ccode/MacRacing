# APEX Lab 3.0 Preview 60 — Mac 驾驶模拟

解压后双击 **APEX Lab.app**。游戏支持 Apple Silicon Mac 和 macOS 14 或更新版本。

`APEX Lab Data` 优先保存到应用旁边。该目录不可写时，数据保存在 `~/Library/Application Support/APEX Lab`。

在「设置 → 画面」可选 120 FPS。驾驶输入的目标读取间隔约 4.17 毫秒，实际设备送来新数据的频率取决于连接方式。键盘轻点 A/D 或左右方向键可微调车头，持续按住可打满，反打时会先快速回正。

## 第一次开始

| 想做什么 | 从哪里开始 |
| --- | --- |
| 学习停车、松刹入弯和湿地出弯 | 「驾驶学院」按顺序选择课程。前两课用 Porsche 911 Carrera 4S，湿地出弯用 Lamborghini Centenario。 |
| 熟悉一条赛道 | 从主界面选车、赛道和路况，进入练习。按 F7 切换仪表，F8 查看练习分析，F9 切换干湿地。 |
| 和电脑对手比赛 | 在「比赛设置」选择圈数、对手、发车位和路况。F10 按当前配置发车。开启单圈排位时，先滚动出场，通过计时线后开始排位。 |
| 跑三站巡回赛 | 选择俱乐部杯、雨地杯或速度杯。每站前四名获 10、7、5、3 分，铜、银、金牌需要 14、20、27 分。 |

911 的旧车重最佳圈可在「驾驶记录 → 练习最佳圈 → 查看旧车重成绩」调出，现行车重单独计时。

练习中按 F8，将鼠标移到图上的弯道位置，再选「放大弯段 10×」。左右方向键逐点查看最近圈与最快圈，实线显示踏板，刹车图内的虚线显示管路压力。方向盘读数标出左、右和角度，旧圈缺失的读数显示为「—」。

正赛灭灯起步。主赛道上相同计时点测出的用时差显示在榜单。蓝旗提示即将被套圈，领跑者完赛后其他车手在各自下一次有效过线时结算。结算页可展开逐圈时间，并打开比赛回放。

松刹入弯课的结果分别记录带刹车转向、逐步松刹和完全松刹后的最长持续时间。逐步松刹看转向负荷下踏板和刹车液压是否同时下降。定点停车课看停车位置距中心的偏差，湿地出弯课看提前大油门和带油打滑的时间。

## 两款车辆与车库

- **Porsche 911 Carrera 4S (992)** 配备原作者的 Aerokit 外观与座舱，采用八挡 PDK 和实验四驱预设。整备质量按美国版 2020 Carrera 4S Coupé PDK 的 3487 磅（约 1582 公斤）计算。
- **Lamborghini Centenario LP-770** 配备带剪刀门的原作者外观和座舱，采用七挡传动与实验四驱预设。后轮在低速反向转动、高速与前轮同向。

从主界面进入「车辆展示」。鼠标可点击车门、盖板和车灯，拖动环绕，滚动缩放。手柄可用右摇杆旋转、LT / RT 缩放、Y 切换观察视角。可开的活动部件取决于各车模型。驾驶舱可左右观察原车后视镜。回放也可切到驾驶舱或选择跟拍、引擎盖、赛道机位，查看当时的车速、油门、刹车行程与液压。

## 赛道、轮胎和维修

六条原创赛道都有干湿地。北环赛道与俱乐部短环适合熟悉连续转向，技术公园与河谷环线有回头弯，大奖赛长环和高原高速环提供较长直道。湿地自定义赛可在「正赛水膜」开启「雨后渐干」，轮胎经过的路线会逐渐减少水膜。

四轮面板显示温度、热态胎压、胎面余量、接地路面和爆胎状态。暂停菜单可设定下次更换的胎种和冷胎压。正赛选「进站策略」，可预选换胎、维修或两项同时完成。驶入维修道时留意 60 km/h 限速，停稳在黄框后按 P。单独换胎用时 12 秒，维修用时按车损计算，正赛计时继续。R 只复位，不恢复车损和轮胎；重新开始练习可使用完好车辆。

「驾驶记录 → 练习最佳圈」可按车辆、赛道和干湿地查看最佳圈与分段。练习数据、基础设置、比赛和学院成绩保存在本地。车辆参数仍是实验预设，实际渲染频率由 Mac 性能、显示器和画质共同决定。

## 压缩包内的试听、截图和许可

- `Porsche911-audio.wav` 和 `Centenario-audio.wav` 各为 8 秒，来自 Preview 55 的离线游戏混音。听取停车起步、加速、收油和带刹转向的变化。动力底音采用相关车型的参考实录。
- 「实机截图」目录的索引标注了原生画面和车辆署名。
- 两款原作者车辆模型及其改编预览使用 CC BY 4.0。Porsche 由 JK3Dstudios 制作，Lamborghini 由 SDC PERFORMANCE™️ 制作。环境和部分声音素材采用各自独立的许可。详细作者、原始来源、改动和许可见包内 `THIRD-PARTY-NOTICES.md`，以及应用 `Contents/Resources/Assets/Vehicles/README.md`。

在 911 驾驶位打大角度转向，可以观察方向盘中心和倾角。并排入弯时，两款车的擦胎声来自各自正在滑动的轮胎。正常速度的比赛回放可切到赛道镜头听旁车经过。
